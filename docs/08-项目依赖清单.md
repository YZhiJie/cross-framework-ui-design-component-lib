## 依赖关系图

```
                    ┌──────────┐
                    │ @xui-design/utils│ (internal, 工程脚本)
                    └─────┬────┘
                          │
┌─────────────────────────┴──────────────────────────┐
│                    Root devDeps                      │
│  turbo / typescript / vite / vitest / eslint / ...  │
└─────────────────────────────────────────────────────┘

包间依赖:
@xui-design/shared  ← (无外部依赖)
@xui-design/core    ← @xui-design/shared
@xui-design/styles  ← (无外部依赖)
@xui-design/icons   ← @xui-design/styles
@xui-design/vue     ← @xui-design/core + @xui-design/shared + @xui-design/styles + @xui-design/icons + vue(peer)
@xui-design/react   ← @xui-design/core + @xui-design/shared + @xui-design/styles + @xui-design/icons + react(peer) + use-sync-external-store
```

---

## 关键约束

1. **Vue / React 必须为 peerDependencies**，不打包进产物，由消费方提供
2. **use-sync-external-store** 是唯一运行时依赖（仅 React 17 需要 polyfill）
3. **workspace:\*** 用于 Monorepo 内部包引用，确保本地开发链路完整
4. **React 版本兼容**：dev 用 19，peer 声明 `>=17.0.0`，运行时检测版本
5. **Vue 版本兼容**：dev 用 3.4，peer 声明 `>=3.2.0`
