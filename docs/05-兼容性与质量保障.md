# 05 - 兼容性与质量保障

## 概述

本章定义跨框架组件库的兼容性矩阵、测试覆盖策略、可视化预览方案和打包体积优化指标，确保双端组件质量一致、版本可控。

## 一、版本兼容范围

### 1.1 框架版本兼容矩阵

| 框架 | 最低支持版本 | 推荐版本 | 依赖关键特性 | 兼容策略 |
|------|:----------:|:-------:|-------------|---------|
| Vue | 3.2.0 | 3.4+ | Composition API, `<script setup>`, `defineModel` | peerDependencies 声明 `>=3.2.0` |
| React | 17.0.0 | 18.2+ | Hooks, `useSyncExternalStore`(18+), `forwardRef` | peerDependencies 声明 `>=17.0.0` |
| React DOM | 17.0.0 | 18.2+ | Portal, `createRoot` | peerDependencies 声明 `>=17.0.0` |
| TypeScript | 5.0.0 | 5.4+ | `satisfies`, `const` type params | devDependencies |
| Node.js | 18.0.0 | 20 LTS+ | ESM, fetch API | engines 声明 |

### 1.3 React 17 vs 18 差异处理

`useSyncExternalStore` 是 React 18 API，React 17 需 polyfill：

```typescript
// @xui/react/src/hooks/use-sync-external-store.ts
import { useSyncExternalStore as ReactUseSyncExternalStore } from 'react';
import { useSyncExternalStore as shim } from 'use-sync-external-store/shim';

// 优先使用原生 API，React 17 fallback 到 shim
const useSyncExternalStore =
  typeof ReactUseSyncExternalStore === 'function'
    ? ReactUseSyncExternalStore
    : shim;

export { useSyncExternalStore };
```

### 2.2 核心层单元测试（@xui/shared）

纯逻辑测试，无需 DOM 环境，执行速度极快：

```typescript
// packages/shared/src/components/button/__tests__/use-button-logic.test.ts
import { describe, it, expect, vi } from 'vitest';
import { createButtonLogic } from '../use-button-logic';

describe('createButtonLogic', () => {
  it('初始化状态正确', () => {
    const logic = createButtonLogic({ disabled: false, loading: false });
    expect(logic.getState()).toEqual({ loading: false, disabled: false });
  });

  it('disabled 状态下点击不触发回调', () => {
    const onClick = vi.fn();
    const logic = createButtonLogic({ disabled: true, onClick });
    logic.handleClick({} as MouseEvent);
    expect(onClick).not.toHaveBeenCalled();
  });

  it('点击时设置 loading 并调用回调', async () => {
    const onClick = vi.fn().mockResolvedValue(undefined);
    const logic = createButtonLogic({ onClick });
    const states: any[] = [];
    logic.subscribe((s) => states.push(s));

    await logic.handleClick({} as MouseEvent);

    expect(onClick).toHaveBeenCalledOnce();
    expect(states).toContainEqual({ loading: true, disabled: false });
    expect(states.at(-1)).toEqual({ loading: false, disabled: false });
  });

  it('updateOptions 更新配置并同步状态', () => {
    const logic = createButtonLogic({});
    const states: any[] = [];
    logic.subscribe((s) => states.push(s));

    logic.updateOptions({ disabled: true });

    expect(logic.getState().disabled).toBe(true);
    expect(states.at(-1)?.disabled).toBe(true);
  });
});
```

#### Vue 组件测试

```typescript
// packages/vue/src/components/button/__tests__/button.test.ts
import { describe, it, expect } from 'vitest';
import { mount } from '@vue/test-utils';
import { Button } from '../button.vue';

describe('Button (Vue)', () => {
  it('渲染默认按钮', () => {
    const wrapper = mount(Button, {
      slots: { default: '确定' },
    });
    expect(wrapper.text()).toContain('确定');
    expect(wrapper.classes()).toContain('xui-button');
    expect(wrapper.classes()).toContain('xui-button--default');
  });

  it('type 属性正确传递', () => {
    const wrapper = mount(Button, { props: { type: 'primary' } });
    expect(wrapper.classes()).toContain('xui-button--primary');
  });

  it('disabled 时点击不触发 click 事件', async () => {
    const wrapper = mount(Button, { props: { disabled: true } });
    await wrapper.trigger('click');
    expect(wrapper.emitted('click')).toBeFalsy();
  });

  it('点击触发 click 事件', async () => {
    const wrapper = mount(Button);
    await wrapper.trigger('click');
    expect(wrapper.emitted('click')).toHaveLength(1);
  });

  it('loading 时显示加载图标且禁用', () => {
    const wrapper = mount(Button, { props: { loading: true } });
    expect(wrapper.find('.xui-button__loading-icon').exists()).toBe(true);
    expect(wrapper.attributes('disabled')).toBeDefined();
  });
});
```

### 2.4 契约测试（Contract Test）

确保 Vue/React 两端 API 完全对齐：

```typescript
// packages/utils/src/contract-test.ts
import { describe, it, expect } from 'vitest';
import { buttonSpec } from '@xui/core/components/button';
import { Button as VueButton } from '@xui/vue/components/button';
import { Button as ReactButton } from '@xui/react/components/button';

describe('Button 契约对齐', () => {
  const spec = buttonSpec;

  it('Vue 组件名与 Spec 一致', () => {
    expect(VueButton.name).toBe(spec.name);
  });

  it('React 组件 displayName 与 Spec 一致', () => {
    expect(ReactButton.displayName).toBe(spec.name);
  });

  it('Vue/React Props 类型定义一致', async () => {
    const vueTypes = await extractPropsType(VueButton);
    const reactTypes = await extractPropsType(ReactButton);
    expect(vueTypes).toEqual(reactTypes);
  });

  it('双端默认值一致', () => {
    // 校验所有可选 Prop 的默认值在 Vue withDefaults 和 React defaultProps 中一致
    const vueDefaults = extractVueDefaults(VueButton);
    const reactDefaults = extractReactDefaults(ReactButton);
    expect(vueDefaults).toEqual(reactDefaults);
  });
});
```

## 四、打包体积优化指标

### 4.1 体积指标定义

| 指标 | 定义 | 目标 |
|------|------|:----:|
| 单组件体积（gzipped） | 单个组件 ESM 产物 gzip 后大小 | < 5KB |
| 核心层体积（gzipped） | @xui/shared 全量 gzip | < 15KB |
| Vue 适配层全量（gzipped） | @xui/vue 全量 gzip | < 40KB |
| React 适配层全量（gzipped） | @xui/react 全量 gzip | < 40KB |
| 样式全量（gzipped） | @xui/styles 全量 gzip | < 20KB |
| 按需加载增量 | 仅引入 1 个组件的 gzip 增量 | < 3KB |

### 4.2 体积预算表

| 包 | 未压缩 | Gzip | Brotli | 预算上限 |
|----|--------|------|--------|---------|
| @xui/shared | ~40KB | ~12KB | ~10KB | 15KB gzip |
| @xui/core | ~15KB | ~4KB | ~3KB | 5KB gzip |
| @xui/styles | ~50KB | ~15KB | ~12KB | 20KB gzip |
| @xui/vue (全量) | ~100KB | ~30KB | ~25KB | 40KB gzip |
| @xui/react (全量) | ~100KB | ~30KB | ~25KB | 40KB gzip |
| @xui/icons (全量) | ~80KB | ~20KB | ~15KB | 25KB gzip |

### 4.3 体积优化措施

| 措施 | 节省量 | 实现方式 |
|------|--------|---------|
| Tree Shaking | ~60% | `sideEffects: false` + ESM + preserveModules |
| 按需加载 | ~80% | 子路径 exports + 自动导入插件 |
| CSS 提取 | ~15% | CSS Modules 独立文件，不内联 |
| 图标按需 | ~90% | SVG 组件化，不打包整包 |
| 去除 PropTypes | ~5% | 生产构建移除 React PropTypes |
| 压缩 | ~70% | Terser + gzip + brotli |

### 4.5 体积回归报警

```typescript
// scripts/bundle-size-diff.ts
// 对比上次 CI 的体积，超过阈值则报警

import { readFileSync, existsSync } from 'fs';

interface SizeRecord {
  path: string;
  gzipSize: number;
}

const PREV_FILE = 'reports/bundle-size-prev.json';
const CURR_FILE = 'reports/bundle-size.json';
const THRESHOLD = 0.1; // 10% 增长即报警

if (!existsSync(PREV_FILE)) {
  console.log('⚠️ 无历史记录，跳过对比');
  process.exit(0);
}

const prev: SizeRecord[] = JSON.parse(readFileSync(PREV_FILE, 'utf-8'));
const curr: SizeRecord[] = JSON.parse(readFileSync(CURR_FILE, 'utf-8'));

let hasRegression = false;
for (const c of curr) {
  const p = prev.find(p => p.path === c.path);
  if (!p) continue;
  const diff = c.gzipSize - p.gzipSize;
  const diffPct = (diff / p.gzipSize) * 100;
  if (diffPct > THRESHOLD * 100) {
    console.error(`❌ ${c.path}: +${diffPct.toFixed(1)}% (${p.gzipSize}KB → ${c.gzipSize}KB)`);
    hasRegression = true;
  }
}

if (hasRegression) process.exit(1);
```
