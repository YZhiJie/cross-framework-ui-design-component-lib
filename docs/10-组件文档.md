# 10 - 组件文档（通用组件库）

> **用途**：XUI 通用组件的功能特性、使用场景、API 说明与注意事项。
> **适用范围**：`@xui/vue` 与 `@xui/react` 双端组件，API 以 `@xui/core` 的 ComponentSpec 为唯一契约基准（见 [03-统一组件规范](./03-统一组件规范.md)）。
> **维护约定**：每新增一批组件，在本文件追加对应章节；API 变更需同步更新本文件与 `scripts/contract-test.ts` 校验矩阵。

## 组件总览

| 分类 | 组件 | 包路径 | 说明 |
|------|------|--------|------|
| 表单交互 | Switch | `@xui/vue` / `@xui/react` | 开关选择器 |
| 表单交互 | Checkbox | `@xui/vue` / `@xui/react` | 复选框（含半选态） |
| 表单交互 | RadioGroup / Radio | `@xui/vue` / `@xui/react` | 单选组 / 单选项（组上下文联动） |
| 表单交互 | Select | `@xui/vue` / `@xui/react` | 下拉选择器（ARIA combobox 模式） |
| 数据展示 | Tag | `@xui/vue` / `@xui/react` | 标签（可关闭） |
| 数据展示 | Progress | `@xui/vue` / `@xui/react` | 进度条（线性 / 圆环） |
| 数据展示 | Badge | `@xui/vue` / `@xui/react` | 徽标数（包裹 / 独立模式） |
| 数据展示 | Avatar | `@xui/vue` / `@xui/react` | 头像（图片 / 文字 / 图标回退） |
| 数据展示 | Empty | `@xui/vue` / `@xui/react` | 空状态 |
| 导航布局 | Tabs | `@xui/vue` / `@xui/react` | 标签页（ARIA tabs 模式） |
| 反馈提示 | Alert | `@xui/vue` / `@xui/react` | 警告提示（可关闭） |
| 反馈提示 | Message | `@xui/vue` / `@xui/react` | 全局消息提示（命令式 API） |
| 基础 | Button / Input / Modal | `@xui/vue` / `@xui/react` | 首批组件（见 playground） |

### 通用约定

- **受控 / 非受控**：提供 `value` 即受控（组件不自改状态，仅回调外部同步）；不提供则非受控，用 `defaultValue` 指定初始状态。Vue 端推荐 `v-model:value`（等价于 `value` + `@update:value`）。
- **事件映射**：core 契约的 `onXxx` 回调 prop，在 Vue 端映射为 `emit('xxx')`（如 `@change`、`@close`），在 React 端映射为 `onXxx`（如 `onChange`、`onClose`）。
- **插槽映射**：Vue 具名插槽 `#title` 对应 React `renderTitle` 回调；作用域插槽对应回调函数类型 Props。
- **样式**：双端共用 `@xui/styles` 单一来源的 BEM 类名（`xui-*`）与 CSS 变量主题（`--xui-*`），引入 `import '@xui/styles'` 即可。
- **尺寸**：统一 `sm | md`（Button/Input 为 `sm | md | lg`）。
- **命令式组件**：Message 采用 `message.success('...')` 形态的命令式函数 API（双端同构），不走 Props / Events / Slots 契约（详见 Message 章节）。

## Switch 开关

### 功能特性

- 受控 / 非受控双模式，非受控模式内部自维护选中状态
- `sm / md` 两种尺寸
- `disabled` 禁用、`loading` 加载态（加载中切换被忽略，滑块显示 Spinner）
- 通过 `ref` 暴露 `focus()` 命令式聚焦（React 端 `SwitchRef`）

### 使用场景

布尔设置的即时开关：通知开关、功能启停、协议同意等二选一场景。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `boolean` | — | 受控选中状态（提供即受控） |
| `defaultValue` | `boolean` | `false` | 非受控初始状态 |
| `size` | `'sm' \| 'md'` | `'md'` | 尺寸 |
| `disabled` | `boolean` | `false` | 禁用 |
| `loading` | `boolean` | `false` | 加载中（切换被忽略） |
| `onChange` | `(value: boolean) => void` | — | 状态变更回调 |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `change` | `onChange` | 切换后的选中值 |
| `update:value` | — | `v-model:value` 回写 |

| Slots（Vue） | React | 说明 |
|--------------|-------|------|
| — | — | 无插槽 |

### 使用示例

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Switch } from '@xui/vue';

const enabled = ref(false);
</script>

<template>
  <!-- 受控（推荐 v-model） -->
  <Switch v-model:value="enabled" @change="(v) => console.log(v)" />
  <!-- 非受控 -->
  <Switch default-value size="sm" />
  <!-- 禁用 / 加载 -->
  <Switch disabled />
  <Switch loading />
</template>
```

```tsx
import { useState } from 'react';
import { Switch } from '@xui/react';

function Demo() {
  const [enabled, setEnabled] = useState(false);
  return (
    <>
      {/* 受控 */}
      <Switch value={enabled} onChange={setEnabled} />
      {/* 非受控 */}
      <Switch defaultValue size="sm" />
      <Switch disabled />
      <Switch loading />
    </>
  );
}
```

### 边界场景处理

- `disabled` / `loading` 状态下点击不触发任何回调（逻辑层 `toggle()` 直接忽略）
- 受控模式下外部未同步 `value` 时，组件视觉状态随外部值回退（严格受控语义）
- `loading` 由 `true` 变回 `false` 后恢复可交互

### 无障碍

- 根元素为 `<button role="switch">`，`aria-checked` 同步选中状态
- 禁用 / 加载时设置 `aria-disabled` 与 `disabled` 属性，阻止键盘触发
- 支持键盘 `Space` / `Enter` 触发（原生 button 语义）

### 注意事项

- Vue 端**不要**用 `:value="false"` 之外的方式"假装非受控"——提供 `value` 即进入受控模式；非受控请完全省略 `value`（Vue 的 Boolean prop 缺省会转 `false`，组件内部已通过 `withDefaults` 的显式 `undefined` 默认值规避，使用者无需关心，但请勿在中间层二次包装 Props 转发）
- 受控模式下请务必在 `change` / `update:value` 回调中回写 `value`，否则视觉状态不更新

## Checkbox 复选框

### 功能特性

- 受控 / 非受控双模式
- 半选态（`indeterminate`）：视觉显示横线，点击后切换为全选
- `disabled` 禁用
- 通过 `ref` 暴露 `focus()`（React 端 `CheckboxRef`）
- 默认插槽渲染标签文案

### 使用场景

多选列表、协议勾选、表格行选择（配合 `indeterminate` 实现全选/部分选中）。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `boolean` | — | 受控选中状态（提供即受控） |
| `defaultValue` | `boolean` | `false` | 非受控初始状态 |
| `disabled` | `boolean` | `false` | 禁用 |
| `indeterminate` | `boolean` | `false` | 半选状态 |
| `onChange` | `(value: boolean) => void` | — | 状态变更回调 |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `change` | `onChange` | 切换后的选中值 |
| `update:value` | — | `v-model:value` 回写 |

| Slots（Vue） | React | 说明 |
|--------------|-------|------|
| `default` | `children` | 标签内容 |

### 使用示例

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Checkbox } from '@xui/vue';

const agreed = ref(false);
</script>

<template>
  <Checkbox v-model:value="agreed">同意服务条款</Checkbox>
  <Checkbox :indeterminate="true">半选（点击后切全选）</Checkbox>
  <Checkbox disabled>禁用</Checkbox>
</template>
```

```tsx
import { useState } from 'react';
import { Checkbox } from '@xui/react';

function Demo() {
  const [agreed, setAgreed] = useState(false);
  return (
    <>
      <Checkbox value={agreed} onChange={setAgreed}>同意服务条款</Checkbox>
      <Checkbox indeterminate>半选（点击后切全选）</Checkbox>
      <Checkbox disabled>禁用</Checkbox>
    </>
  );
}
```

### 边界场景处理

- 半选态点击 → 切换为**全选**（不是取消），并清除半选视觉；非受控时逻辑层自动清除 `indeterminate`，受控时由外部管理
- `disabled` 时点击无效
- `indeterminate` 与 `checked` 同时提供时，视觉以 `indeterminate`（横线）优先

### 无障碍

- 使用原生 `<input type="checkbox">`，键盘与读屏行为完全继承浏览器原生语义
- 半选状态通过 DOM 属性 `indeterminate` 同步（读屏可感知）
- 外层 `label` 包裹，点击文案即可切换

### 注意事项

- `indeterminate` 既是视觉态也是交互初态：受控模式下若外部一直传 `indeterminate: true`，每次点击都会切为全选并触发 `change(true)`，需要外部自行同步清除
- 半选是 DOM 属性而非 HTML attribute，React 端经 `useEffect` + ref 同步，Vue 端经 `.prop` 修饰符绑定，均已在实现内处理

## Tag 标签

### 功能特性

- 5 种语义类型：`default / primary / success / warning / danger`
- `sm / md` 两种尺寸
- `closable` 可关闭：显示关闭按钮，点击后隐藏并触发 `close`
- 关闭为组件内部状态（`visible`），关闭后组件渲染为 `null`

### 使用场景

内容标记、分类标注、筛选条件回显、列表条目状态展示。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `type` | `'default' \| 'primary' \| 'success' \| 'warning' \| 'danger'` | `'default'` | 语义类型 |
| `size` | `'sm' \| 'md'` | `'md'` | 尺寸 |
| `closable` | `boolean` | `false` | 是否可关闭 |
| `onClose` | `() => void` | — | 关闭回调（组件隐藏后触发） |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `close` | `onClose` | 无 |

| Slots（Vue） | React | 说明 |
|--------------|-------|------|
| `default` | `children` | 标签内容 |

### 使用示例

```vue
<template>
  <Tag>default</Tag>
  <Tag type="success">success</Tag>
  <Tag type="danger" size="sm">danger</Tag>
  <Tag closable @close="onClose">可关闭</Tag>
</template>
```

```tsx
<Tag type="success">success</Tag>
<Tag closable onClose={() => console.log('closed')}>可关闭</Tag>
```

### 边界场景处理

- 重复触发关闭（连续点击 ×）：`handleClose()` 幂等，仅首次生效
- 关闭是纯前端行为（内部 `visible` 状态），如需"删除后从数据源移除"，在 `close` 回调中自行处理数据

### 无障碍

- 关闭按钮为原生 `<button>`，`aria-label="close"`，可键盘聚焦触发

### 注意事项

- 组件关闭后不再渲染（`v-if` / `return null`），如需恢复显示需重建组件或自行管理外层 `v-if`
- `onClose` 在组件隐藏**之后**触发，回调中不要再操作该组件实例

## Alert 警告提示

### 功能特性

- 4 种语义类型：`info / success / warning / error`，各配对应图标
- `title` 标题 + `description` 描述两级信息结构
- `showIcon` 显示类型图标
- `closable` 可关闭，关闭后隐藏并触发 `close`
- 插槽体系：标题、描述、图标均可自定义

### 使用场景

页面内重要信息的强提示：操作结果反馈、表单校验汇总、系统公告、危险操作警示。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `type` | `'info' \| 'success' \| 'warning' \| 'error'` | `'info'` | 语义类型 |
| `title` | `string` | — | 标题 |
| `description` | `string` | — | 描述（default 插槽的回退内容） |
| `closable` | `boolean` | `false` | 是否可关闭 |
| `showIcon` | `boolean` | `false` | 是否显示类型图标 |
| `onClose` | `() => void` | — | 关闭回调（组件隐藏后触发） |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `close` | `onClose` | 无 |

| Slots（Vue） | React 回调 | 说明 |
|--------------|------------|------|
| `default` | `children` | 描述内容（覆盖 `description`） |
| `title` | `renderTitle` | 标题（覆盖 `title`） |
| `icon` | `renderIcon` | 类型图标（覆盖默认图标，`showIcon` 开启时生效） |

### 使用示例

```vue
<template>
  <Alert title="Info" description="普通信息提示" show-icon />
  <Alert type="success" title="Success" description="操作已完成" show-icon />
  <Alert type="warning" title="Warning" description="请检查输入" show-icon />
  <Alert type="error" title="Error" description="出错了" show-icon closable @close="onClose" />

  <!-- 自定义标题与描述 -->
  <Alert type="info" show-icon>
    <template #title>自定义标题</template>
    支持 <b>HTML</b> 的描述内容
  </Alert>
</template>
```

```tsx
<Alert title="Info" description="普通信息提示" showIcon />
<Alert type="error" title="Error" description="出错了" showIcon closable onClose={handleClose} />

{/* 自定义标题与描述 */}
<Alert type="info" showIcon renderTitle={() => <em>自定义标题</em>}>
  支持 <b>HTML</b> 的描述内容
</Alert>
```

### 边界场景处理

- 重复触发关闭：`handleClose()` 幂等，仅首次生效
- `title` 与 `description` 均未提供时仍渲染容器（可完全由插槽接管内容）
- 优先级：插槽 / render 回调 > 同名 prop（`#title` > `title`，`#default` > `description`）

### 无障碍

- 根元素 `role="alert"`：动态出现时读屏自动播报
- 图标容器 `aria-hidden="true"`，避免读屏重复朗读
- 关闭按钮 `aria-label="close"`

### 注意事项

- `role="alert"` 适合**动态插入**的提示；对常驻静态提示建议外层自行降级为 `role="status"`（如需）
- 图标为 `@xui/icons` 单一来源 SVG，自定义图标时用 `#icon` / `renderIcon` 完整替换

## RadioGroup 单选组

### 功能特性

- 受控 / 非受控双模式；`options` 数组渲染与 `default` 插槽渲染两种用法（`options` 优先）
- 整组 `disabled`；单个选项可通过 `options` 项的 `disabled` 或 `Radio` 的 `disabled` 独立禁用
- 组内原生 `<input type="radio">` 共用同一 `name`（实例级唯一自动生成），获得浏览器原生互斥与方向键导航
- 组上下文联动：`Radio` 子项通过 provide/inject（Vue）/ Context（React）消费组状态，选中变更统一由组触发 `change`

### 使用场景

互斥单选：性别、支付方式、枚举配置项等（选项 ≤ 5 时建议用 RadioGroup，更多选项用 Select）。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `string` | — | 受控选中值（提供即受控） |
| `defaultValue` | `string` | — | 非受控初始选中值 |
| `disabled` | `boolean` | `false` | 整组禁用 |
| `options` | `{ label: string; value: string; disabled?: boolean }[]` | — | 选项数组（提供时优先渲染） |
| `onChange` | `(value: string) => void` | — | 选中值变更回调 |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `change` | `onChange` | 新选中的 value |
| `update:value` | — | `v-model:value` 回写 |

| Slots（Vue） | React | 说明 |
|--------------|-------|------|
| `default` | `children` | 自定义选项（渲染 `Radio` 子项） |

### 使用示例

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { RadioGroup, Radio } from '@xui/vue';

const city = ref('beijing');
const options = [
  { label: '北京', value: 'beijing' },
  { label: '上海', value: 'shanghai' },
  { label: '广州（停用）', value: 'gz', disabled: true },
];
</script>

<template>
  <!-- options 渲染 -->
  <RadioGroup v-model:value="city" :options="options" @change="(v) => console.log(v)" />
  <!-- 插槽渲染 -->
  <RadioGroup v-model:value="city">
    <Radio value="beijing">北京</Radio>
    <Radio value="shanghai">上海</Radio>
  </RadioGroup>
</template>
```

```tsx
import { useState } from 'react';
import { RadioGroup, Radio } from '@xui/react';

function Demo() {
  const [city, setCity] = useState('beijing');
  return (
    <RadioGroup value={city} onChange={setCity}>
      <Radio value="beijing">北京</Radio>
      <Radio value="shanghai" disabled>上海</Radio>
    </RadioGroup>
  );
}
```

### 边界场景处理

- `disabled`（整组或单选项）时 `select` 被静默忽略，不更新状态、不触发 `change`
- 受控模式下外部未回写 `value` 时，选中视觉随外部值回退（严格受控语义；Vue 端在 change 处理器中手动恢复 DOM，React 端由受控机制自动恢复）
- `options` 与插槽子项同时提供时，`options` 优先渲染
- 选中相同 value 的重复点击不产生多余状态更新

### 无障碍

- 根元素 `role="radiogroup"`
- 原生 `<input type="radio">` 保证键盘方向键在组内切换、读屏播报选中项
- 禁用项设置 `disabled` 与 `aria-disabled`

### 注意事项

- `Radio` 设计为 `RadioGroup` 的子项组件，**组外渲染仅作兜底**（永不选中、点击不产生任何效果）
- 受控模式请在 `change` / `update:value` 回调中回写 `value`，否则视觉不更新

## Radio 单选项

### 功能特性

- 仅承载单选项自身属性（`value` / `disabled`），选中状态派生自所在组的组值
- 组外渲染作兜底：永不选中（双端一致）
- 自身禁用的程序化触发守卫：绕过原生 `disabled` 的事件（如测试工具 `fireEvent`）同样被忽略并恢复 DOM 状态

### 使用场景

作为 `RadioGroup` 的子项使用（见 RadioGroup 示例）。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `string` | — | 选项值（组内唯一，必填） |
| `disabled` | `boolean` | `false` | 禁用本项 |

无契约事件（选中变更统一由 RadioGroup 触发 `change`）。

| Slots（Vue） | React | 说明 |
|--------------|-------|------|
| `default` | `children` | 选项文案 |

### 无障碍

- 原生 `<input type="radio">`（label 包裹，点击文案即可选中）
- 键盘聚焦时自定义圆点显示 `:focus-visible` 焦点环
- 选中/禁用状态以 `is-checked` / `is-disabled` 类名呈现并同步原生属性

## Progress 进度条

### 功能特性

- `line` 线性 / `circle` 圆环两种类型
- 状态色：显式 `status: 'success' | 'error'` 优先；否则 `percent >= 100` 自动进入 success
- 数值归一化：非有限数值回退 0，超出 `[0, 100]` 自动 clamp；`strokeWidth` 非法回退 6
- 纯展示组件，无交互事件

### 使用场景

任务进度、上传/下载进度、步骤完成度、表单填写完成率等。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `percent` | `number` | `0` | 进度百分比（自动 clamp 到 0–100） |
| `type` | `'line' \| 'circle'` | `'line'` | 类型 |
| `strokeWidth` | `number` | `6` | 线性条高度 / 圆环描边宽度 |
| `showText` | `boolean` | `true` | 是否显示百分比文本 |
| `status` | `'normal' \| 'success' \| 'error'` | `'normal'` | 状态色 |

无事件、无插槽。

### 使用示例

```vue
<template>
  <Progress :percent="60" />
  <Progress :percent="100" />
  <Progress :percent="72" status="error" />
  <Progress type="circle" :percent="75" />
</template>
```

```tsx
<Progress percent={60} />
<Progress percent={100} />
<Progress percent={72} status="error" />
<Progress type="circle" percent={75} />
```

### 边界场景处理

- `percent` 传 `NaN` / `Infinity` / 负数 → 按 0 处理；超过 100 → 按 100 处理（文本仍显示真实 clamp 后的整数）
- `percent >= 100` 自动派生 success 状态（绿色）；显式 `status` 优先于自动派生
- `strokeWidth` 非法（非有限 / ≤ 0）回退默认 6

### 无障碍

- 根元素 `role="progressbar"`，`aria-valuenow`（取整）/ `aria-valuemin` / `aria-valuemax` 同步
- 圆环 SVG `aria-hidden="true"`，语义由容器承载

## Badge 徽标数

- 包裹模式（有 children）：徽标叠加在内容右上角；独立模式：徽标单独渲染

| `dot` | `boolean` | `false` | 点状徽标（忽略 count 文本） |
| `showZero` | `boolean` | `false` | count 为 0 时是否显示 |

无事件。

| Slots（Vue） | React | 说明 |
|--------------|-------|------|
| `default` | `children` | 徽标包裹的内容（省略时独立渲染） |

```vue
  <Badge :count="9" /><!-- 独立模式 -->
</template>
```

```tsx

<Badge count={120}><Button>99+</Button></Badge>
```

### 边界场景处理

- `count` 未提供 / 非有限数值（如 NaN）→ 不渲染徽标（双端一致，包裹模式下不渲染 sup 元素）
- `count = 0` 默认隐藏，`showZero` 开启后显示 "0"

## Select 下拉选择器

### 功能特性

- 受控 / 非受控双模式；`options` 数组配置渲染
- 整体 `disabled`；单个选项可通过 `options` 项的 `disabled` 独立禁用
- `clearable`：已选中时显示清除图标，点击清空并触发 `clear`
- 完整键盘支持：`Enter` / `Space` 展开（或确认高亮项）、`Escape` 收起、`ArrowDown` / `ArrowUp` 移动高亮（跳过禁用项、循环）
- 点击面板外部自动收起
- ARIA combobox 交互模型（见无障碍）

### 使用场景

枚举选项较多的单选场景（选项 > 5 时替代 RadioGroup）：城市选择、分类筛选、表单枚举字段等。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `string` | — | 受控选中值（提供即受控） |
| `defaultValue` | `string` | — | 非受控初始选中值 |
| `options` | `{ label: string; value: string; disabled?: boolean }[]` | — | 选项数组（必填） |
| `placeholder` | `string` | — | 未选中时的占位文案 |
| `disabled` | `boolean` | `false` | 整体禁用 |
| `clearable` | `boolean` | `false` | 已选中时显示清除图标 |
| `onChange` | `(value: string) => void` | — | 选中值变更回调 |
| `onClear` | `() => void` | — | 点击清除图标回调 |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `change` | `onChange` | 新选中的 value |
| `clear` | `onClear` | 无 |
| `update:value` | — | `v-model:value` 回写 |

无插槽。

### 使用示例

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Select } from '@xui/vue';

const city = ref('');
const options = [
  { label: '北京', value: 'beijing' },
  { label: '上海（停用）', value: 'shanghai', disabled: true },
  { label: '广州', value: 'guangzhou' },
];
</script>

<template>
  <!-- 非受控 + 清除 -->
  <Select :options="options" placeholder="请选择城市" clearable @clear="onClear" />
  <!-- 受控（推荐 v-model） -->
  <Select v-model:value="city" :options="options" @change="(v) => console.log(v)" />
  <!-- 整体禁用 -->
  <Select :options="options" disabled placeholder="Disabled" />
</template>
```

```tsx
import { useState } from 'react';
import { Select } from '@xui/react';

function Demo() {
  const [city, setCity] = useState('');
  return (
    <>
      <Select options={options} placeholder="请选择城市" clearable onClear={handleClear} />
      <Select value={city} onChange={setCity} options={options} />
      <Select options={options} disabled placeholder="Disabled" />
    </>
  );
}
```

### 边界场景处理

- 禁用项点击被忽略：不更新值、不收起面板、不产生高亮
- 选中当前已选中的值：仅收起面板，不重复触发 `change`
- 点击清除图标：非受控置回空（显示 placeholder）并触发 `clear`；受控模式下 `clear` 回调始终触发，`value` 是否同步由外部决定（与 Input 清除语义一致）
- 整体 `disabled`：触发器不可聚焦（tabindex -1）、不展开面板、清除图标不可点
- 点击面板外部（document `mousedown`）自动收起

### 无障碍

- 触发器 `role="combobox"`，携带 `aria-expanded` / `aria-haspopup="listbox"` / `aria-controls`（指向面板）/ `aria-activedescendant`（指向键盘高亮项）/ `aria-disabled`；禁用时 tabindex -1
- 面板 `role="listbox"`；选项 `role="option"` + `aria-selected` / `aria-disabled`
- 键盘：`Enter` / `Space` 展开或确认高亮项、`Escape` 收起、`ArrowDown` / `ArrowUp` 移动高亮（跳过禁用项、循环）

### 注意事项

- `options` 为必填数组；未选中时内部值为 `null`
- 键盘高亮态（`is-active`）是交互态，选中态（`is-selected`）是值态，二者独立呈现
- 受控模式请在 `change` / `update:value` 回调中回写 `value`

## Tabs 标签页

### 功能特性

- 受控 / 非受控双模式；`items` 数组配置驱动
- 单项 `disabled` 禁用（点击与键盘激活均忽略）
- 键盘左右切换：`ArrowRight` / `ArrowLeft` 切换到下一个 / 上一个可用项（跳过禁用项、循环），焦点跟随激活项
- roving tabindex：仅激活项可 Tab 聚焦
- 面板内容支持作用域插槽（Vue `#default="{ item }"` ↔ React `renderPanel`），缺省回退渲染 `item.label`

### 使用场景

平级内容分区的页内导航：详情页信息分区、设置页分组、向导步骤切换等。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `string` | — | 受控激活值（提供即受控） |
| `defaultValue` | `string` | — | 非受控初始激活值 |
| `items` | `{ label: string; value: string; disabled?: boolean }[]` | — | 标签页配置（必填） |
| `onChange` | `(value: string) => void` | — | 激活项变更回调 |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `change` | `onChange` | 新激活项 value |
| `update:value` | — | `v-model:value` 回写 |

| Slots（Vue） | React 回调 | 作用域 |
|--------------|------------|--------|
| `default` | `renderPanel` | `{ item: TabItem }`（当前激活项） |

### 使用示例

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Tabs } from '@xui/vue';

const active = ref('a');
const items = [
  { label: '标签一', value: 'a' },
  { label: '标签二（停用）', value: 'b', disabled: true },
  { label: '标签三', value: 'c' },
];
</script>

<template>
  <!-- 受控（推荐 v-model）+ 作用域插槽渲染面板 -->
  <Tabs v-model:value="active" :items="items" @change="(v) => console.log(v)">
    <template #default="{ item }">「{{ item.label }}」的内容区</template>
  </Tabs>
  <!-- 非受控 -->
  <Tabs default-value="a" :items="items" />
</template>
```

```tsx
import { useState } from 'react';
import { Tabs } from '@xui/react';

function Demo() {
  const [active, setActive] = useState('a');
  return (
    <>
      <Tabs value={active} onChange={setActive} items={items} renderPanel={(item) => `「${item.label}」的内容区`} />
      <Tabs defaultValue="a" items={items} />
    </>
  );
}
```

### 边界场景处理

- `disabled` 项：点击与键盘激活均被忽略，激活值不变
- 激活相同 value：no-op，不重复触发 `change`
- `items` 为空 / 全部禁用时激活值保持 `null`，面板渲染插槽 fallback
- 键盘切换从当前激活项出发；无激活项时 `ArrowRight` 定位第一个可用项、`ArrowLeft` 定位最后一个可用项

### 无障碍

- `role="tablist"` / `role="tab"` / `role="tabpanel"` 三级结构
- `aria-selected`（激活态）、`aria-disabled`、`aria-controls`（tab → tabpanel）、`aria-labelledby`（tabpanel → tab）
- roving tabindex + 键盘切换后焦点跟随激活项（`ArrowRight` / `ArrowLeft`）

### 注意事项

- 面板内容由 **default 作用域插槽**统一渲染：Vue 用 `#default="{ item }"`，React 用 `renderPanel` 回调；不要写 `#item` 具名插槽（不会被消费）
- 受控模式请在 `change` / `update:value` 回调中回写 `value`

## Message 全局提示（命令式）

### 功能特性

- 命令式 API：`message.info / success / warning / error / open / closeAll`，双端同构
- 4 种语义类型（info / success / warning / error），各配对应图标与色板（与 Alert 一致）
- 自动关闭（`duration` 默认 3000ms，`0` 表示不自动关闭）+ 手动关闭（`closable` 或句柄 `close()`）
- `maxCount`（默认 5）：同屏超限时自动移除最早一条
- 首次调用自动挂载全局容器（页面顶部居中，fixed 定位），无需在应用中预置组件

### 使用场景

操作结果的轻量全局反馈：保存成功、请求失败、复制完成等（不打断操作的提示，区别于 Modal / Alert）。

### API（命令式）

| 方法 | 签名 | 说明 |
|------|------|------|
| `message.info` | `(content: string, options?) => MessageHandle` | info 消息 |
| `message.success` | 同上 | success 消息 |
| `message.warning` | 同上 | warning 消息 |
| `message.error` | 同上 | error 消息 |
| `message.open` | `(options: MessageOptions) => MessageHandle` | 完整选项打开 |
| `message.closeAll` | `() => void` | 关闭全部消息 |

`MessageOptions`：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `content` | `string` | — | 消息内容（必填） |
| `type` | `'info' \| 'success' \| 'warning' \| 'error'` | `'info'` | 语义类型 |
| `duration` | `number` | `3000` | 自动关闭时长（ms），`0` 表示不自动关闭 |
| `closable` | `boolean` | `false` | 是否显示关闭按钮 |

`MessageHandle`：`{ close: () => void }`（手动关闭该条消息）。快捷方法的 `options` 仅支持 `duration` / `closable`（`type` / `content` 由方法注入）。

默认值单一来源：`messageDefaults`（`@xui/core` re-export 自 `@xui/shared`）。

### 使用示例

```vue
<script setup lang="ts">
import { message } from '@xui/vue';

message.info('普通提示');
message.success('保存成功');
message.warning('请注意输入');
message.error('请求失败');

// 完整选项 + 手动关闭句柄
const handle = message.open({ type: 'info', content: '不自动关闭', duration: 0, closable: true });
// handle.close();
message.closeAll();
</script>
```

```tsx
import { message } from '@xui/react';

message.success('保存成功');
const handle = message.open({ type: 'error', content: '请求失败', duration: 0, closable: true });
// handle.close();
message.closeAll();
```

### 边界场景处理

- `maxCount` 超限：移除最早一条（连带其自动关闭定时器），新消息始终追加
- `duration: 0`：不自动关闭，仅可通过关闭按钮、句柄 `close()` 或 `closeAll()` 关闭
- 句柄 `close()` 幂等：重复关闭或对已移除消息操作均静默，不报错
- `closeAll()` 同时清空全部定时器与渲染队列

### 无障碍

- 消息容器 `aria-live="polite"`：新消息出现时读屏播报（不打断当前朗读）
- 关闭按钮 `aria-label="close"`；类型图标 `aria-hidden="true"`

### 注意事项

- Message 是命令式 API，**不是声明式组件**：双端均未导出 `Message` 组件，直接从包入口导入 `message` 单例调用
- 不进 `contract-test.ts` 声明式校验矩阵（无 Props / Events / Slots 契约），契约基准为 core 类型定义与 `messageDefaults`
- 双端 API 完全同构（`@xui/vue` / `@xui/react` 各自导出 `message`），在对应框架入口直接调用即可

- **playground 插槽写法修正**：Vue 端 Tabs 面板作用域插槽为 default 插槽（`#default="{ item }"`），具名 `#item` 不会被消费
- **样式规则**：`:not()` 使用逗号复合写法（stylelint `selector-not-notation: complex`）；hover 态选择器须排在同前缀 `is-disabled` 派生规则之后（`no-descending-specificity`）

### 批次 2 修复记录

- **Vue 受控同步 bug（影响批次 1 组件）**：`withDefaults(defineProps<T>(), {...})` 配合解构返回值会禁用 Vue 3.5 的响应式解构（编译器警告证实），解构变量退化为一次性快照，`watchEffect` 依赖收集失效，导致受控 Props 变更无法同步视觉状态。修复：`RadioGroup.vue` / `Switch.vue` / `Checkbox.vue` 改为 `const props = withDefaults(...)`，解构快照仅用于逻辑层初始化，后续 Props 访问一律走 `props.xxx`；并补齐双端"受控 setProps 驱动视觉切换"测试用例
- **React Badge 包裹模式补齐 `state.visible` 判断**：count 隐藏时不再渲染空的 sup 元素（与 Vue 端对齐）
- **Radio 自身禁用守卫**：程序化事件（测试工具 `fireEvent` 等）会绕过原生 `disabled` 行为，双端 handleChange 增加自身禁用忽略 + DOM 恢复守卫

### 双端一致性保障

- `scripts/contract-test.ts` 校验矩阵覆盖每个组件的：事件（emits ↔ 回调 prop）、Props 齐全性、默认值（Vue 编译产物 props 选项 ↔ React 源码解构默认值 ↔ core 契约 spec）三方逐项比对
- Vue 端默认值必须写在 `withDefaults` 第二参数（才会编译进 props 选项）；解构模式中的等号默认值只是 setup 局部回退，契约测试会拦截此类不一致
- Vue 端 `value` / `defaultValue` 使用显式 `undefined` 默认值跳过 Boolean prop 缺省转换，保证"提供即受控"语义与 React 端对齐

### 已知限制

- 组件样式依赖 `@xui/styles`（BEM + CSS 变量），未引入主题 token 时使用降级值
- 长期驻留的 Vite dev server 若在 `@xui/core` 类型产物重建前启动，SFC 类型解析缓存可能被污染（表现为编译报 `Unresolvable type reference`），重启 dev server 即可恢复
