# 10 - 组件文档（通用组件库）

> **用途**：XUI 通用组件的功能特性、使用场景、API 说明与注意事项。
> **适用范围**：`@xui/vue` 与 `@xui/react` 双端组件，API 以 `@xui/core` 的 ComponentSpec 为唯一契约基准（见 [03-统一组件规范](./03-统一组件规范.md)）。

### 通用约定

- **受控 / 非受控**：提供 `value` 即受控（组件不自改状态，仅回调外部同步）；不提供则非受控，用 `defaultValue` 指定初始状态。Vue 端推荐 `v-model:value`（等价于 `value` + `@update:value`）。
- **事件映射**：core 契约的 `onXxx` 回调 prop，在 Vue 端映射为 `emit('xxx')`（如 `@change`、`@close`），在 React 端映射为 `onXxx`（如 `onChange`、`onClose`）。
- **插槽映射**：Vue 具名插槽 `#title` 对应 React `renderTitle` 回调；作用域插槽对应回调函数类型 Props。
- **样式**：双端共用 `@xui/styles` 单一来源的 BEM 类名（`xui-*`）与 CSS 变量主题（`--xui-*`），引入 `import '@xui/styles'` 即可。
- **尺寸**：统一 `sm | md`（Button/Input 为 `sm | md | lg`）。
- **命令式组件**：Message 采用 `message.success('...')` 形态的命令式函数 API（双端同构），不走 Props / Events / Slots 契约（详见 Message 章节）。

## Switch 开关

### 功能特性

- 受控 / 非受控双模式，非受控模式内部自维护选中状态
- `sm / md` 两种尺寸
- `disabled` 禁用、`loading` 加载态（加载中切换被忽略，滑块显示 Spinner）
- 通过 `ref` 暴露 `focus()` 命令式聚焦（React 端 `SwitchRef`）

### 使用场景

布尔设置的即时开关：通知开关、功能启停、协议同意等二选一场景。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `boolean` | — | 受控选中状态（提供即受控） |
| `defaultValue` | `boolean` | `false` | 非受控初始状态 |
| `size` | `'sm' \| 'md'` | `'md'` | 尺寸 |
| `disabled` | `boolean` | `false` | 禁用 |
| `loading` | `boolean` | `false` | 加载中（切换被忽略） |
| `onChange` | `(value: boolean) => void` | — | 状态变更回调 |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `change` | `onChange` | 切换后的选中值 |
| `update:value` | — | `v-model:value` 回写 |

| Slots（Vue） | React | 说明 |
|--------------|-------|------|
| — | — | 无插槽 |

### 使用示例

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Switch } from '@xui/vue';

const enabled = ref(false);
</script>

<template>
  <!-- 受控（推荐 v-model） -->
  <Switch v-model:value="enabled" @change="(v) => console.log(v)" />
  <!-- 非受控 -->
  <Switch default-value size="sm" />
  <!-- 禁用 / 加载 -->
  <Switch disabled />
  <Switch loading />
</template>
```

```tsx
import { useState } from 'react';
import { Switch } from '@xui/react';

function Demo() {
  const [enabled, setEnabled] = useState(false);
  return (
    <>
      {/* 受控 */}
      <Switch value={enabled} onChange={setEnabled} />
      {/* 非受控 */}
      <Switch defaultValue size="sm" />
      <Switch disabled />
      <Switch loading />
    </>
  );
}
```

### 边界场景处理

- `disabled` / `loading` 状态下点击不触发任何回调（逻辑层 `toggle()` 直接忽略）
- 受控模式下外部未同步 `value` 时，组件视觉状态随外部值回退（严格受控语义）
- `loading` 由 `true` 变回 `false` 后恢复可交互

### 无障碍

- 根元素为 `<button role="switch">`，`aria-checked` 同步选中状态
- 禁用 / 加载时设置 `aria-disabled` 与 `disabled` 属性，阻止键盘触发
- 支持键盘 `Space` / `Enter` 触发（原生 button 语义）

### 注意事项

- Vue 端**不要**用 `:value="false"` 之外的方式"假装非受控"——提供 `value` 即进入受控模式；非受控请完全省略 `value`（Vue 的 Boolean prop 缺省会转 `false`，组件内部已通过 `withDefaults` 的显式 `undefined` 默认值规避，使用者无需关心，但请勿在中间层二次包装 Props 转发）
- 受控模式下请务必在 `change` / `update:value` 回调中回写 `value`，否则视觉状态不更新

## Checkbox 复选框

### 功能特性

- 受控 / 非受控双模式
- 半选态（`indeterminate`）：视觉显示横线，点击后切换为全选
- `disabled` 禁用
- 通过 `ref` 暴露 `focus()`（React 端 `CheckboxRef`）
- 默认插槽渲染标签文案

### 使用场景

多选列表、协议勾选、表格行选择（配合 `indeterminate` 实现全选/部分选中）。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `boolean` | — | 受控选中状态（提供即受控） |
| `defaultValue` | `boolean` | `false` | 非受控初始状态 |
| `disabled` | `boolean` | `false` | 禁用 |
| `indeterminate` | `boolean` | `false` | 半选状态 |
| `onChange` | `(value: boolean) => void` | — | 状态变更回调 |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `change` | `onChange` | 切换后的选中值 |
| `update:value` | — | `v-model:value` 回写 |

| Slots（Vue） | React | 说明 |
|--------------|-------|------|
| `default` | `children` | 标签内容 |

### 使用示例

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Checkbox } from '@xui/vue';

const agreed = ref(false);
</script>

<template>
  <Checkbox v-model:value="agreed">同意服务条款</Checkbox>
  <Checkbox :indeterminate="true">半选（点击后切全选）</Checkbox>
  <Checkbox disabled>禁用</Checkbox>
</template>
```

```tsx
import { useState } from 'react';
import { Checkbox } from '@xui/react';

function Demo() {
  const [agreed, setAgreed] = useState(false);
  return (
    <>
      <Checkbox value={agreed} onChange={setAgreed}>同意服务条款</Checkbox>
      <Checkbox indeterminate>半选（点击后切全选）</Checkbox>
      <Checkbox disabled>禁用</Checkbox>
    </>
  );
}
```

### 边界场景处理

- 半选态点击 → 切换为**全选**（不是取消），并清除半选视觉；非受控时逻辑层自动清除 `indeterminate`，受控时由外部管理
- `disabled` 时点击无效
- `indeterminate` 与 `checked` 同时提供时，视觉以 `indeterminate`（横线）优先

### 无障碍

- 使用原生 `<input type="checkbox">`，键盘与读屏行为完全继承浏览器原生语义
- 半选状态通过 DOM 属性 `indeterminate` 同步（读屏可感知）
- 外层 `label` 包裹，点击文案即可切换

### 注意事项

- `indeterminate` 既是视觉态也是交互初态：受控模式下若外部一直传 `indeterminate: true`，每次点击都会切为全选并触发 `change(true)`，需要外部自行同步清除
- 半选是 DOM 属性而非 HTML attribute，React 端经 `useEffect` + ref 同步，Vue 端经 `.prop` 修饰符绑定，均已在实现内处理

## Tag 标签

### 功能特性

- 5 种语义类型：`default / primary / success / warning / danger`
- `sm / md` 两种尺寸
- `closable` 可关闭：显示关闭按钮，点击后隐藏并触发 `close`
- 关闭为组件内部状态（`visible`），关闭后组件渲染为 `null`

### 使用场景

内容标记、分类标注、筛选条件回显、列表条目状态展示。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `type` | `'default' \| 'primary' \| 'success' \| 'warning' \| 'danger'` | `'default'` | 语义类型 |
| `size` | `'sm' \| 'md'` | `'md'` | 尺寸 |
| `closable` | `boolean` | `false` | 是否可关闭 |
| `onClose` | `() => void` | — | 关闭回调（组件隐藏后触发） |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `close` | `onClose` | 无 |

| Slots（Vue） | React | 说明 |
|--------------|-------|------|
| `default` | `children` | 标签内容 |

### 使用示例

```vue
<template>
  <Tag>default</Tag>
  <Tag type="success">success</Tag>
  <Tag type="danger" size="sm">danger</Tag>
  <Tag closable @close="onClose">可关闭</Tag>
</template>
```

```tsx
<Tag type="success">success</Tag>
<Tag closable onClose={() => console.log('closed')}>可关闭</Tag>
```

### 边界场景处理

- 重复触发关闭（连续点击 ×）：`handleClose()` 幂等，仅首次生效
- 关闭是纯前端行为（内部 `visible` 状态），如需"删除后从数据源移除"，在 `close` 回调中自行处理数据

### 无障碍

- 关闭按钮为原生 `<button>`，`aria-label="close"`，可键盘聚焦触发

### 注意事项

- 组件关闭后不再渲染（`v-if` / `return null`），如需恢复显示需重建组件或自行管理外层 `v-if`
- `onClose` 在组件隐藏**之后**触发，回调中不要再操作该组件实例

## Alert 警告提示

### 功能特性

- 4 种语义类型：`info / success / warning / error`，各配对应图标
- `title` 标题 + `description` 描述两级信息结构
- `showIcon` 显示类型图标
- `closable` 可关闭，关闭后隐藏并触发 `close`
- 插槽体系：标题、描述、图标均可自定义

### 使用场景

页面内重要信息的强提示：操作结果反馈、表单校验汇总、系统公告、危险操作警示。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `type` | `'info' \| 'success' \| 'warning' \| 'error'` | `'info'` | 语义类型 |
| `title` | `string` | — | 标题 |
| `description` | `string` | — | 描述（default 插槽的回退内容） |
| `closable` | `boolean` | `false` | 是否可关闭 |
| `showIcon` | `boolean` | `false` | 是否显示类型图标 |
| `onClose` | `() => void` | — | 关闭回调（组件隐藏后触发） |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `close` | `onClose` | 无 |

| Slots（Vue） | React 回调 | 说明 |
|--------------|------------|------|
| `default` | `children` | 描述内容（覆盖 `description`） |
| `title` | `renderTitle` | 标题（覆盖 `title`） |
| `icon` | `renderIcon` | 类型图标（覆盖默认图标，`showIcon` 开启时生效） |

### 使用示例

```vue
<template>
  <Alert title="Info" description="普通信息提示" show-icon />
  <Alert type="success" title="Success" description="操作已完成" show-icon />
  <Alert type="warning" title="Warning" description="请检查输入" show-icon />
  <Alert type="error" title="Error" description="出错了" show-icon closable @close="onClose" />

  <!-- 自定义标题与描述 -->
  <Alert type="info" show-icon>
    <template #title>自定义标题</template>
    支持 <b>HTML</b> 的描述内容
  </Alert>
</template>
```

```tsx
<Alert title="Info" description="普通信息提示" showIcon />
<Alert type="error" title="Error" description="出错了" showIcon closable onClose={handleClose} />

{/* 自定义标题与描述 */}
<Alert type="info" showIcon renderTitle={() => <em>自定义标题</em>}>
  支持 <b>HTML</b> 的描述内容
</Alert>
```

### 边界场景处理

- 重复触发关闭：`handleClose()` 幂等，仅首次生效
- `title` 与 `description` 均未提供时仍渲染容器（可完全由插槽接管内容）
- 优先级：插槽 / render 回调 > 同名 prop（`#title` > `title`，`#default` > `description`）

### 无障碍

- 根元素 `role="alert"`：动态出现时读屏自动播报
- 图标容器 `aria-hidden="true"`，避免读屏重复朗读
- 关闭按钮 `aria-label="close"`

### 注意事项

- `role="alert"` 适合**动态插入**的提示；对常驻静态提示建议外层自行降级为 `role="status"`（如需）
- 图标为 `@xui/icons` 单一来源 SVG，自定义图标时用 `#icon` / `renderIcon` 完整替换

## RadioGroup 单选组

### 功能特性

- 受控 / 非受控双模式；`options` 数组渲染与 `default` 插槽渲染两种用法（`options` 优先）
- 整组 `disabled`；单个选项可通过 `options` 项的 `disabled` 或 `Radio` 的 `disabled` 独立禁用
- 组内原生 `<input type="radio">` 共用同一 `name`（实例级唯一自动生成），获得浏览器原生互斥与方向键导航
- 组上下文联动：`Radio` 子项通过 provide/inject（Vue）/ Context（React）消费组状态，选中变更统一由组触发 `change`

### 使用场景

互斥单选：性别、支付方式、枚举配置项等（选项 ≤ 5 时建议用 RadioGroup，更多选项用 Select）。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `string` | — | 受控选中值（提供即受控） |
| `defaultValue` | `string` | — | 非受控初始选中值 |
| `disabled` | `boolean` | `false` | 整组禁用 |
| `options` | `{ label: string; value: string; disabled?: boolean }[]` | — | 选项数组（提供时优先渲染） |
| `onChange` | `(value: string) => void` | — | 选中值变更回调 |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `change` | `onChange` | 新选中的 value |
| `update:value` | — | `v-model:value` 回写 |

| Slots（Vue） | React | 说明 |
|--------------|-------|------|
| `default` | `children` | 自定义选项（渲染 `Radio` 子项） |

### 使用示例

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { RadioGroup, Radio } from '@xui/vue';

const city = ref('beijing');
const options = [
  { label: '北京', value: 'beijing' },
  { label: '上海', value: 'shanghai' },
  { label: '广州（停用）', value: 'gz', disabled: true },
];
</script>

<template>
  <!-- options 渲染 -->
  <RadioGroup v-model:value="city" :options="options" @change="(v) => console.log(v)" />
  <!-- 插槽渲染 -->
  <RadioGroup v-model:value="city">
    <Radio value="beijing">北京</Radio>
    <Radio value="shanghai">上海</Radio>
  </RadioGroup>
</template>
```

```tsx
import { useState } from 'react';
import { RadioGroup, Radio } from '@xui/react';

function Demo() {
  const [city, setCity] = useState('beijing');
  return (
    <RadioGroup value={city} onChange={setCity}>
      <Radio value="beijing">北京</Radio>
      <Radio value="shanghai" disabled>上海</Radio>
    </RadioGroup>
  );
}
```

### 边界场景处理

- `disabled`（整组或单选项）时 `select` 被静默忽略，不更新状态、不触发 `change`
- 受控模式下外部未回写 `value` 时，选中视觉随外部值回退（严格受控语义；Vue 端在 change 处理器中手动恢复 DOM，React 端由受控机制自动恢复）
- `options` 与插槽子项同时提供时，`options` 优先渲染
- 选中相同 value 的重复点击不产生多余状态更新

### 无障碍

- 根元素 `role="radiogroup"`
- 原生 `<input type="radio">` 保证键盘方向键在组内切换、读屏播报选中项
- 禁用项设置 `disabled` 与 `aria-disabled`

### 注意事项

- `Radio` 设计为 `RadioGroup` 的子项组件，**组外渲染仅作兜底**（永不选中、点击不产生任何效果）
- 受控模式请在 `change` / `update:value` 回调中回写 `value`，否则视觉不更新

## Radio 单选项

### 功能特性

- 仅承载单选项自身属性（`value` / `disabled`），选中状态派生自所在组的组值
- 组外渲染作兜底：永不选中（双端一致）
- 自身禁用的程序化触发守卫：绕过原生 `disabled` 的事件（如测试工具 `fireEvent`）同样被忽略并恢复 DOM 状态

### 使用场景

作为 `RadioGroup` 的子项使用（见 RadioGroup 示例）。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `string` | — | 选项值（组内唯一，必填） |
| `disabled` | `boolean` | `false` | 禁用本项 |

无契约事件（选中变更统一由 RadioGroup 触发 `change`）。

| Slots（Vue） | React | 说明 |
|--------------|-------|------|
| `default` | `children` | 选项文案 |

### 无障碍

- 原生 `<input type="radio">`（label 包裹，点击文案即可选中）
- 键盘聚焦时自定义圆点显示 `:focus-visible` 焦点环
- 选中/禁用状态以 `is-checked` / `is-disabled` 类名呈现并同步原生属性

## Progress 进度条

### 功能特性

- `line` 线性 / `circle` 圆环两种类型

|-------|------|--------|------|
| `percent` | `number` | `0` | 进度百分比（自动 clamp 到 0–100） |
| `type` | `'line' \| 'circle'` | `'line'` | 类型 |
| `strokeWidth` | `number` | `6` | 线性条高度 / 圆环描边宽度 |
| `showText` | `boolean` | `true` | 是否显示百分比文本 |
| `status` | `'normal' \| 'success' \| 'error'` | `'normal'` | 状态色 |

无事件、无插槽。

### 使用示例

```vue
<template>
  <Progress :percent="60" />
  <Progress :percent="100" />
  <Progress :percent="72" status="error" />
  <Progress type="circle" :percent="75" />

```

```tsx
<Progress percent={60} />
<Progress percent={100} />
<Progress percent={72} status="error" />
<Progress type="circle" percent={75} />
```

### 边界场景处理

- `percent` 传 `NaN` / `Infinity` / 负数 → 按 0 处理；超过 100 → 按 100 处理（文本仍显示真实 clamp 后的整数）
- `percent >= 100` 自动派生 success 状态（绿色）；显式 `status` 优先于自动派生

## Select 下拉选择器

### 功能特性

- 受控 / 非受控双模式；`options` 数组配置渲染
- `multiple` 多选：选中值为 `string[]`，点击选项切换选中且面板不关闭；trigger 以 tag 展示选中项，tag 可单独移除（再点即取消）
- `searchable` 可搜索：面板顶部搜索框按选项文案过滤（大小写不敏感），键盘导航作用于过滤后列表
- `virtual` 虚拟滚动：1000+ 选项仅渲染可视窗口（固定行高 + spacer 占位），`maxHeight` 控制面板视口高度
- `className` / `style` 自定义透传（`style` 支持 CSS 自定义属性，如 `--xui-select-max-height`）
- 整体 `disabled`；单个选项可通过 `options` 项的 `disabled` 独立禁用
- `clearable`：已选中时显示清除图标（多选时清空全部），点击清空并触发 `clear`
- 完整键盘支持：`Enter` / `Space` 展开（或确认高亮项）、`Escape` 收起、`ArrowDown` / `ArrowUp` 移动高亮（跳过禁用项、循环）；搜索框内 `Space` 为正常输入
- 点击面板外部自动收起（同时重置搜索状态）
- ARIA combobox 交互模型（见无障碍）

### 使用场景

- 枚举选项较多的单选场景（选项 > 5 时替代 RadioGroup）：城市选择、分类筛选、表单枚举字段等
- 多选标签场景：兴趣标签、权限分配等（`multiple`）
- 需按文案快速定位选项的检索式选择（`searchable`）
- 选项上千条的大数据量选择（`virtual`）

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `string \| string[]` | — | 受控选中值（提供即受控）；多选模式为 `string[]` |
| `defaultValue` | `string \| string[]` | — | 非受控初始选中值 |
| `options` | `{ label: string; value: string; disabled?: boolean }[]` | — | 选项数组（必填） |
| `placeholder` | `string` | — | 未选中时的占位文案 |
| `disabled` | `boolean` | `false` | 整体禁用 |
| `clearable` | `boolean` | `false` | 已选中时显示清除图标；多选时清空全部 |
| `multiple` | `boolean` | `false` | 多选模式：点击选项切换选中且面板不关闭 |
| `searchable` | `boolean` | `false` | 面板顶部搜索框按文案过滤 |
| `virtual` | `boolean` | `false` | 虚拟滚动模式（大数据量选项） |
| `maxHeight` | `number` | `264` | 面板最大高度（px）；虚拟模式下即视口高度 |
| `className` | `string` | — | 附加到根节点的自定义类名 |
| `style` | `Record<string, string>` | — | 附加到根节点的内联样式（支持 CSS 自定义属性） |
| `onChange` | `(value: string \| string[]) => void` | — | 选中值变更回调（多选载荷为最新数组） |
| `onClear` | `() => void` | — | 点击清除图标回调 |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `change` | `onChange` | 最新选中值（多选为 `string[]`） |
| `clear` | `onClear` | 无 |
| `update:value` | — | `v-model:value` 回写 |

无插槽。

### 使用示例


### 边界场景处理

- 禁用项点击被忽略：不更新值、不收起面板、不产生高亮
- 单选选中当前已选中的值：仅收起面板，不重复触发 `change`；多选点击选项为切换语义（取消选中同样触发 `change`）
- 多选删除 tag：等价于再次点击该选项（切换取消），`onChange` 携带最新数组
- 点击清除图标：非受控置回空（显示 placeholder）并触发 `clear`；受控模式下 `clear` 回调始终触发，`value` 是否同步由外部决定（与 Input 清除语义一致）
- 搜索无匹配：面板显示"无匹配结果"空态；关闭面板后自动清空搜索词
- 搜索词为纯空白：不过滤（视为未搜索）
- 虚拟模式滚动/搜索联动：过滤后自动重置滚动位置，避免 scrollTop 越界空白
- 整体 `disabled`：触发器不可聚焦（tabindex -1）、不展开面板、清除图标不可点
- 点击面板外部（document `mousedown`）自动收起并重置搜索状态

### 无障碍

- 触发器 `role="combobox"`，携带 `aria-expanded` / `aria-haspopup="listbox"` / `aria-controls`（指向面板）/ `aria-activedescendant`（指向键盘高亮项）/ `aria-disabled`；禁用时 tabindex -1
- 面板 `role="listbox"`，多选时携带 `aria-multiselectable`；选项 `role="option"` + `aria-selected` / `aria-disabled`
- 搜索框独立 `role="searchbox"`；键盘高亮项变化自动 `scrollIntoView` 保持可见
- 键盘：`Enter` / `Space` 展开或确认高亮项、`Escape` 收起、`ArrowDown` / `ArrowUp` 移动高亮（跳过禁用项、循环）；搜索框内 `Space` 为正常输入字符

### 注意事项

- `options` 为必填数组；单选未选中时内部值为 `null`，多选未选中时为空数组 `[]`
- `onChange` 载荷类型为 `string | string[]`（多选加宽）：旧代码 `onChange={(v: string) => ...}` 需收窄或使用 `String(v)`；单选行为与旧版完全一致
- 虚拟模式要求选项行高固定（逻辑层 30px，与 CSS 变量 `--xui-select-item-height` 默认值一致；自定义行高需同时覆盖该变量）
- 键盘高亮态（`is-active`）是交互态，选中态（`is-selected`）是值态，二者独立呈现
- 受控模式请在 `change` / `update:value` 回调中回写 `value`

## Tabs 标签页

### 功能特性

- 受控 / 非受控双模式；`items` 数组配置驱动
- 单项 `disabled` 禁用（点击与键盘激活均忽略）
- 键盘左右切换：`ArrowRight` / `ArrowLeft` 切换到下一个 / 上一个可用项（跳过禁用项、循环），焦点跟随激活项
- roving tabindex：仅激活项可 Tab 聚焦
- 面板内容支持作用域插槽（Vue `#default="{ item }"` ↔ React `renderPanel`），缺省回退渲染 `item.label`

### 使用场景

平级内容分区的页内导航：详情页信息分区、设置页分组、向导步骤切换等。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `string` | — | 受控激活值（提供即受控） |
| `defaultValue` | `string` | — | 非受控初始激活值 |
| `items` | `{ label: string; value: string; disabled?: boolean }[]` | — | 标签页配置（必填） |
| `onChange` | `(value: string) => void` | — | 激活项变更回调 |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `change` | `onChange` | 新激活项 value |
| `update:value` | — | `v-model:value` 回写 |

| Slots（Vue） | React 回调 | 作用域 |
|--------------|------------|--------|
| `default` | `renderPanel` | `{ item: TabItem }`（当前激活项） |

### 使用示例

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Tabs } from '@xui/vue';

const active = ref('a');
const items = [
  { label: '标签一', value: 'a' },
  { label: '标签二（停用）', value: 'b', disabled: true },
  { label: '标签三', value: 'c' },
];
</script>

<template>
  <!-- 受控（推荐 v-model）+ 作用域插槽渲染面板 -->
  <Tabs v-model:value="active" :items="items" @change="(v) => console.log(v)">
    <template #default="{ item }">「{{ item.label }}」的内容区</template>
  </Tabs>
  <!-- 非受控 -->
  <Tabs default-value="a" :items="items" />
</template>
```

```tsx
import { useState } from 'react';
import { Tabs } from '@xui/react';

function Demo() {
  const [active, setActive] = useState('a');
  return (
    <>
      <Tabs value={active} onChange={setActive} items={items} renderPanel={(item) => `「${item.label}」的内容区`} />
      <Tabs defaultValue="a" items={items} />
    </>
  );
}
```

### 边界场景处理

- `disabled` 项：点击与键盘激活均被忽略，激活值不变
- 激活相同 value：no-op，不重复触发 `change`
- `items` 为空 / 全部禁用时激活值保持 `null`，面板渲染插槽 fallback
- 键盘切换从当前激活项出发；无激活项时 `ArrowRight` 定位第一个可用项、`ArrowLeft` 定位最后一个可用项

### 无障碍

- `role="tablist"` / `role="tab"` / `role="tabpanel"` 三级结构
- `aria-selected`（激活态）、`aria-disabled`、`aria-controls`（tab → tabpanel）、`aria-labelledby`（tabpanel → tab）
- roving tabindex + 键盘切换后焦点跟随激活项（`ArrowRight` / `ArrowLeft`）

### 注意事项

- 面板内容由 **default 作用域插槽**统一渲染：Vue 用 `#default="{ item }"`，React 用 `renderPanel` 回调；不要写 `#item` 具名插槽（不会被消费）
- 受控模式请在 `change` / `update:value` 回调中回写 `value`

## Message 全局提示（命令式）

### 功能特性

- 命令式 API：`message.info / success / warning / error / open / closeAll`，双端同构
- 4 种语义类型（info / success / warning / error），各配对应图标与色板（与 Alert 一致）
- 自动关闭（`duration` 默认 3000ms，`0` 表示不自动关闭）+ 手动关闭（`closable` 或句柄 `close()`）
- `maxCount`（默认 5）：同屏超限时自动移除最早一条
- `key` 更新语义：相同 `key` 再次 `open` 原地更新该条消息（不新增、重置计时），适合上传进度等场景
- `onClose` 回调：消息被移除（自动 / 手动 / 挤出 / `closeAll`）时触发
- 首次调用自动挂载全局容器（页面顶部居中，fixed 定位），无需在应用中预置组件

### 使用场景

操作结果的轻量全局反馈：保存成功、请求失败、复制完成等（不打断操作的提示，区别于 Modal / Alert）。

### API（命令式）

| 方法 | 签名 | 说明 |
|------|------|------|
| `message.info` | `(content: string, options?) => MessageHandle` | info 消息 |
| `message.success` | 同上 | success 消息 |
| `message.warning` | 同上 | warning 消息 |
| `message.error` | 同上 | error 消息 |
| `message.open` | `(options: MessageOptions) => MessageHandle` | 完整选项打开 |
| `message.closeAll` | `() => void` | 关闭全部消息 |

`MessageOptions`：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `content` | `string` | — | 消息内容（必填） |
| `type` | `'info' \| 'success' \| 'warning' \| 'error'` | `'info'` | 语义类型 |
| `duration` | `number` | `3000` | 自动关闭时长（ms），`0` 表示不自动关闭 |
| `closable` | `boolean` | `false` | 是否显示关闭按钮 |
| `key` | `string \| number` | — | 更新键：相同 key 再次 `open` 原地更新该条（不新增、重置计时） |
| `onClose` | `() => void` | — | 消息移除回调（自动 / 手动 / 挤出 / `closeAll`） |

`MessageHandle`：`{ close: () => void }`（手动关闭该条消息）。快捷方法的 `options` 仅支持 `duration` / `closable`（`type` / `content` 由方法注入；`key` / `onClose` 需走 `message.open`）。

默认值单一来源：`messageDefaults`（`@xui/core` re-export 自 `@xui/shared`）。

### 使用示例

```vue
<script setup lang="ts">
import { message } from '@xui/vue';

message.info('普通提示');
message.success('保存成功');
message.warning('请注意输入');
message.error('请求失败');

// 完整选项 + 手动关闭句柄
const handle = message.open({ type: 'info', content: '不自动关闭', duration: 0, closable: true });
// handle.close();
message.closeAll();

// key 更新：同 key 原地刷新（上传进度场景）
message.open({ content: '上传中 0%', key: 'upload', duration: 0 });
message.open({ content: '上传完成', key: 'upload', type: 'success', duration: 3000 });
</script>
```

```tsx
import { message } from '@xui/react';

message.success('保存成功');
const handle = message.open({ type: 'error', content: '请求失败', duration: 0, closable: true });
// handle.close();
message.closeAll();

// key 更新 + onClose 回调
message.open({ content: '上传中 0%', key: 'upload', duration: 0 });
message.open({ content: '上传完成', key: 'upload', type: 'success', onClose: () => console.log('closed') });
```

### 边界场景处理

- `maxCount` 超限：移除最早一条（连带其自动关闭定时器），新消息始终追加
- `duration: 0`：不自动关闭，仅可通过关闭按钮、句柄 `close()` 或 `closeAll()` 关闭
- 句柄 `close()` 幂等：重复关闭或对已移除消息操作均静默，不报错
- `closeAll()` 同时清空全部定时器与渲染队列
- `key` 更新：同 key 已存在时原地更新（`content` 必填刷新，`type` / `closable` 未传保留原值），计时以最新 `duration` 重置；更新时若传了 `onClose` 则替换旧回调
- `onClose` 触发时机统一：自动关闭 / 手动关闭 / `maxCount` 挤出 / `closeAll` 均触发（被移除即触发）

### 无障碍

- 消息容器 `aria-live="polite"`：新消息出现时读屏播报（不打断当前朗读）
- 关闭按钮 `aria-label="close"`；类型图标 `aria-hidden="true"`

### 注意事项

- Message 是命令式 API，**不是声明式组件**：双端均未导出 `Message` 组件，直接从包入口导入 `message` 单例调用
- 不进 `contract-test.ts` 声明式校验矩阵（无 Props / Events / Slots 契约），契约基准为 core 类型定义与 `messageDefaults`
- 双端 API 完全同构（`@xui/vue` / `@xui/react` 各自导出 `message`），在对应框架入口直接调用即可

## Modal 对话框

### 功能特性

- 受控 / 非受控双模式：`visible`（提供即受控）/ `defaultVisible`（非受控初始值），Vue 端支持 `v-model:visible`
- Teleport / Portal 到 `document.body`，遮罩 + 居中面板结构
- 关闭路径齐全：右上角关闭按钮（`closable`）、遮罩点击（`maskClosable`）、ESC（`closeOnEsc`，默认开启）、确认 / 取消按钮（触发后自动关闭）
- 焦点管理：打开时自动聚焦面板并记录此前焦点，关闭后焦点恢复到打开前的元素
- 焦点陷阱：打开期间 Tab / Shift+Tab 循环约束在弹窗内（`trapFocus` 默认开启，可关闭）
- `okText` / `cancelText` 自定义底部按钮文案（默认 确认 / 取消）
- 插槽 / 回调自定义：`title` 插槽（React `renderTitle`）、`footer` 插槽（React `renderFooter`）完全覆盖默认底部
- `ref` 命令式 API：`open()` / `close()`（双端对齐 `ModalRef`）

### 使用场景

需要用户聚焦处理的中断式交互：确认操作、表单填写、内容详情预览等（强反馈，区别于 Message / Alert）。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `visible` | `boolean` | — | 受控可见性（提供即受控） |
| `defaultVisible` | `boolean` | `false` | 非受控初始可见性 |
| `title` | `string` | — | 标题（`title` 插槽可覆盖） |
| `width` | `number \| string` | `520` | 面板宽度（数字按 px，字符串原样） |
| `closable` | `boolean` | `true` | 是否显示右上角关闭按钮 |
| `maskClosable` | `boolean` | `true` | 点击遮罩是否关闭 |
| `closeOnEsc` | `boolean` | `true` | 按 ESC 是否关闭 |
| `okText` | `string` | `'确认'` | 确认按钮文案（默认 footer 生效） |
| `cancelText` | `string` | `'取消'` | 取消按钮文案（默认 footer 生效） |
| `trapFocus` | `boolean` | `true` | 打开期间 Tab 焦点是否循环约束在弹窗内 |

| Events（Vue） | React 回调 | 说明 |
|---------------|------------|------|
| `open` | `onOpen` | 弹窗打开后触发 |
| `close` | `onClose` | 弹窗关闭后触发 |
| `ok` | `onOk` | 点击确认按钮（触发后自动关闭） |
| `cancel` | `onCancel` | 点击取消按钮（触发后自动关闭） |

| 插槽（Vue） | React 回调 | 说明 |
|-------------|------------|------|
| `title` | `renderTitle` | 标题区域（覆盖 `title` prop） |
| `footer` | `renderFooter` | 底部操作区（覆盖默认确认 / 取消按钮） |
| `default` | `children` | 弹窗内容 |

`ref`：`{ open: () => void; close: () => void }`（双端对齐 `ModalRef`）。

### 使用示例

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Modal, Button } from '@xui/vue';

const visible = ref(false);
</script>

<template>
  <Button type="primary" @click="visible = true">打开弹窗</Button>
  <Modal v-model:visible="visible" title="标题" :width="480" ok-text="好的" cancel-text="再想想"
    @ok="console.log('ok')" @cancel="console.log('cancel')">
    <p>弹窗内容</p>
  </Modal>
</template>
```

```tsx
import { useRef, useState } from 'react';
import { Modal, Button } from '@xui/react';
import type { ModalRef } from '@xui/react';

function Demo() {
  const [visible, setVisible] = useState(false);
  const ref = useRef<ModalRef>(null);
  return (
    <>
      <Button type="primary" onClick={() => setVisible(true)}>打开弹窗</Button>
      <Modal
        ref={ref}
        visible={visible}
        title="标题"
        width={480}
        okText="好的"
        cancelText="再想想"
        onOk={() => setVisible(false)}
        onCancel={() => setVisible(false)}
      >
        <p>弹窗内容</p>
      </Modal>
    </>
  );
}
```

### 边界场景处理

- `visible` 受控时组件不自改状态：所有关闭路径（ESC / 遮罩 / 按钮）仅回调外部，由外部更新 `visible`（Vue `v-model:visible` 自动回写）
- 命令式 `open()` 与受控并存：`open` 触发 `onOpen` 后由外部对齐受控值（推荐回调中同步 state）
- `closeOnEsc` 关闭时面板 `keydown` 与 `document` 监听双路径均不关闭
- `trapFocus` 打开且面板内无可聚焦元素时，焦点锁定在面板自身（`tabindex="-1"`）
- 关闭后内容销毁（`v-if` / 条件渲染，等效 destroyOnClose）
- 自定义 `footer` 插槽时 `okText` / `cancelText` 不生效（完全由插槽接管）

### 无障碍

- 面板 `role="dialog"` + `aria-modal="true"`
- 焦点陷阱保证键盘用户不会误入弹窗背后的内容；关闭后焦点归还打开前元素
- 关闭按钮 `aria-label="close"`

### 注意事项

- Vue 端回调 Props（`onOpen` / `onClose` / `onOk` / `onCancel`）映射为 `@open` / `@close` / `@ok` / `@cancel`
- 默认 footer 按钮顺序为 取消在前、确认在后；`okText` / `cancelText` 仅影响文案不改变顺序
- 样式类：`xui-modal`（容器）/ `__overlay` / `__panel` / `__header` / `__body` / `__footer` / `__close`

## Tooltip 文字提示

### 功能特性

- `hover` / `focus` 两种触发方式（`trigger` 门控对应事件）
- 四个弹出方位：`top` / `bottom` / `left` / `right`（默认 `top`，CSS 包裹定位，非 portal）
- 悬停提示框本身不消失（popper 为根元素子节点，鼠标移入可查看 / 复制内容）
- `disabled` 禁用触发；运行时禁用会收起已展开的提示框
- 提示内容支持插槽覆盖（Vue `#content` ↔ React `renderContent`），优先级高于 `content` prop

### 使用场景

鼠标悬停 / 聚焦时的辅助说明：按钮含义解释、截断文本全文、图标按钮提示等。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `content` | `string` | — | 提示内容（插槽 / 回调覆盖优先） |
| `placement` | `'top' \| 'bottom' \| 'left' \| 'right'` | `'top'` | 弹出位置 |
| `trigger` | `'hover' \| 'focus'` | `'hover'` | 触发方式 |
| `disabled` | `boolean` | `false` | 禁用状态（不响应触发） |

无契约事件。

| 插槽（Vue） | React 回调 | 说明 |
|-------------|------------|------|
| `default` | `children` | 触发元素 |
| `content` | `renderContent` | 提示内容（覆盖 `content` prop） |

### 使用示例

```vue
<script setup lang="ts">
import { Tooltip, Button } from '@xui/vue';
</script>

<template>
  <Tooltip content="顶部提示（默认）">
    <Button>top</Button>
  </Tooltip>
  <Tooltip content="底部提示" placement="bottom">
    <Button>bottom</Button>
  </Tooltip>
  <Tooltip content="聚焦触发" trigger="focus">
    <Input placeholder="focus 触发" />
  </Tooltip>
  <Tooltip disabled content="不会弹出">
    <Button>disabled</Button>
  </Tooltip>
  <!-- 内容插槽覆盖 -->
  <Tooltip content="被覆盖">
    <template #content><strong>富文本提示</strong></template>
    <Button>slot</Button>
  </Tooltip>
</template>
```

```tsx
import { Tooltip, Button, Input } from '@xui/react';

function Demo() {
  return (
    <>
      <Tooltip content="顶部提示（默认）">
        <Button>top</Button>
      </Tooltip>
      <Tooltip content="底部提示" placement="bottom">
        <Button>bottom</Button>
      </Tooltip>
      <Tooltip content="聚焦触发" trigger="focus">
        <Input placeholder="focus 触发" />
      </Tooltip>
      <Tooltip disabled content="不会弹出">
        <Button>disabled</Button>
      </Tooltip>
      {/* 内容回调覆盖 */}
      <Tooltip content="被覆盖" renderContent={() => <strong>富文本提示</strong>}>
        <Button>slot</Button>
      </Tooltip>
    </>
  );
}
```

### 边界场景处理

- `disabled` 时触发事件被忽略（不展开）；运行时从可用切到禁用会收起已展开的提示框
- 已展开时重复 `show` / 未展开时 `hide` 均为 no-op
- 悬停提示框本身不触发 `mouseleave`（popper 是根元素子节点），鼠标可在提示框内移动
- `trigger="focus"` 时 hover 事件不生效，反之亦然（`trigger` 严格门控）

### 无障碍

- 触发元素携带 `aria-describedby` 指向提示框（展开时）
- 提示框 `role="tooltip"` + 自动生成的 id；箭头 `aria-hidden="true"`

### 注意事项

- 定位为 CSS 包裹定位（相对触发元素 absolute + 四方位类），非 portal 挂载，父容器 `overflow: hidden` 可能裁剪提示框
- 无契约事件（开合状态由组件内部管理），如需控制展开请用 `disabled` + 条件渲染包裹层

## DatePicker 日期选择器

### 功能特性

- 受控 / 非受控双模式；value 契约为 `'YYYY-MM-DD'` 格式字符串（零依赖、序列化友好）
- `clearable`：已选中时显示清除图标，点击清空并触发 `clear`
- 日历面板：星期表头 + 42 格月视图（含上下月补位日期）、今天高亮、选中高亮
- 月份滚动跨年自动处理（`prevMonth` / `nextMonth`）
- 完整键盘支持：`Enter` / `Space` 开合面板、`Escape` 收起
- 点击面板外部自动收起
- ARIA combobox 交互模型（见无障碍）

### 使用场景

单日期选择：表单日期字段、筛选条件、预约时间等。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `string`（`'YYYY-MM-DD'`） | — | 受控选中日期（提供即受控） |
| `defaultValue` | `string`（`'YYYY-MM-DD'`） | — | 非受控初始日期 |
| `placeholder` | `string` | — | 未选中时的占位文案 |
| `disabled` | `boolean` | `false` | 整体禁用 |
| `clearable` | `boolean` | `false` | 已选中时显示清除图标 |
| `onChange` | `(value: string) => void` | — | 选中日期变更回调 |
| `onClear` | `() => void` | — | 点击清除图标回调 |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `change` | `onChange` | `'YYYY-MM-DD'` |
| `clear` | `onClear` | 无 |
| `update:value` | — | `v-model:value` 回写 |

无插槽。

### 使用示例

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DatePicker } from '@xui/vue';

const date = ref('');
</script>

<template>
  <!-- 非受控 + 清除 -->
  <DatePicker placeholder="请选择日期" clearable @clear="onClear" />
  <!-- 受控（推荐 v-model） -->
  <DatePicker v-model:value="date" placeholder="请选择日期" @change="(v) => console.log(v)" />
  <!-- 整体禁用 -->
  <DatePicker disabled placeholder="Disabled" />
</template>
```

```tsx
import { useState } from 'react';
import { DatePicker } from '@xui/react';

function Demo() {
  const [date, setDate] = useState('');
  return (
    <>
      <DatePicker placeholder="请选择日期" clearable onClear={handleClear} />
      <DatePicker value={date} onChange={setDate} placeholder="请选择日期" />
      <DatePicker disabled placeholder="Disabled" />
    </>
  );
}
```

### 边界场景处理

- 非法初始值（如 `2026-02-30`、格式错误）：回退 `null` 显示 placeholder，不抛错（正则 + Date 往返双重校验，覆盖闰年）
- 受控模式下非法 `value` 同样回退 `null`
- 选中日期后面板自动收起；受控模式仅触发 `change` 回调（`value` 是否同步由外部决定）
- `clear`：非受控置回 `null` 并触发 `onClear`；受控模式 `onClear` 始终触发
- 整体 `disabled`：不展开面板、清除图标不可点；运行时禁用会收起已展开的面板
- 点击面板外部（document `mousedown`）自动收起；展开时视图定位到选中值或今天

### 无障碍

- 触发器 `role="combobox"` + `aria-haspopup="dialog"` / `aria-expanded`；键盘 `Enter` / `Space` 开合、`Escape` 收起
- 面板 `role="dialog"` + `aria-label="选择日期"`；头部导航 `role="navigation"`
- 日期格 `aria-label` 为完整 `'YYYY-MM-DD'`；今天 `is-today`、选中 `is-selected` 类标识

### 注意事项

- 契约为字符串而非 Date 对象：读写均为 `'YYYY-MM-DD'`（补零），跨时区序列化安全
- 42 格月视图中的上下月补位日期（`is-outside`）点击同样会选中对应日期
- 星期表头顺序为日 → 六（周日起始）

## Pagination 分页

### 功能特性

- 受控 / 非受控双模式（页码从 1 开始）
- 页码省略号：页数 ≤ 7 全显，否则展示 当前页 ±2 + 首末页 + 省略号
- 上一页 / 下一页导航按钮（边界自动禁用）
- `total` / `pageSize` 变更自动重算总页数并 clamp 当前页
- 完整键盘可达（原生 button + `aria-current`）

### 使用场景

列表 / 表格数据分页导航。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `number` | — | 受控当前页（提供即受控，从 1 开始） |
| `defaultValue` | `number` | — | 非受控初始页码 |
| `total` | `number` | — | 数据总条数（必填） |
| `pageSize` | `number` | `10` | 每页条数 |
| `disabled` | `boolean` | `false` | 整体禁用 |
| `onChange` | `(page: number) => void` | — | 页码变更回调 |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `change` | `onChange` | 新页码 |
| `update:value` | — | `v-model:value` 回写 |

无插槽。

### 使用示例

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Pagination } from '@xui/vue';

const page = ref(2);
</script>

<template>
  <!-- 非受控 -->
  <Pagination :total="285" />
  <!-- 受控（推荐 v-model） -->
  <Pagination v-model:value="page" :total="285" @change="(p) => console.log(p)" />
  <!-- 整体禁用 -->
  <Pagination :total="50" disabled />
</template>
```

```tsx
import { useState } from 'react';
import { Pagination } from '@xui/react';

```

### 边界场景处理

- `goTo` 越界自动 clamp 到 `[1, pageCount]`；跳转当前页为 no-op；`disabled` 时忽略
- 上一页在第一页 / 下一页在最后一页为 no-op（按钮渲染为 disabled）
- `total` 变小导致当前页越界：自动 clamp（如 `total=95` → 10 页 → 当前页 10）
- `pageCount` 最小为 1（`total=0` 时仍显示第 1 页）
- 非法 `total`（负数按 0）/ `pageSize`（小于 1 按 1、小数向下取整）防御性处理

### 无障碍

- 容器 `role="navigation"` + `aria-label="分页"`
- 上一页 / 下一页按钮 `aria-label="上一页"` / `"下一页"`
- 当前页按钮 `aria-current="page"`；省略号 `aria-hidden="true"`

### 注意事项

- 页码省略号策略：页数 ≤ 7 全部展示；否则固定展示首页、末页与当前页 ±2，区间外以 `···` 占位
- 受控模式请在 `change` / `update:value` 回调中回写 `value`

## Table 表格

### 功能特性

- `columns` 列定义 + `dataSource` 行数据渲染（`rowKey` 指定行唯一键，缺省用行下标）
- 列级排序：`sortable` 列点击表头循环 升序 → 降序 → 取消（非受控内部排序，`sortChange` 回调通知）
- 排序值比较：同为 number 数值比较，否则字符串比较（稳定排序，不改原数组）
- 单元格自定义渲染：`columns[].render(record, index)` 返回字符串覆盖默认取值
- `rowSelection` 行选择：全选 / 半选联动、受控 `selectedRowKeys`、`getCheckboxDisabled` 禁用行
- `virtual` 虚拟滚动：1000+ 行仅渲染可视窗口（固定行高 + spacer 占位），`height` / `rowHeight` 控制视口与行高
- `onRowClick` 行点击事件（选择列点击不触发）
- `className` / `style` 自定义透传（根节点，支持 CSS 变量如 `--xui-table-row-height`）
- `stripe` 斑马纹 / `border` 边框模式
- 空数据态：默认"暂无数据"，支持插槽覆盖（Vue `#empty` ↔ React `renderEmpty`）

### 使用场景

结构化数据展示：列表页、详情面板、后台管理表格等。

大数据量表格浏览：配合 `virtual` 虚拟滚动，仅渲染可视窗口，万级行数据流畅滚动。

批量操作列表：配合 `rowSelection` 勾选行，全选 / 半选联动、受控选中键集合。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `columns` | `TableColumn[]` | — | 列定义数组（必填） |
| `dataSource` | `TableRow[]` | — | 行数据数组（必填） |
| `rowKey` | `string` | — | 行唯一键字段名（缺省用行下标；行选择建议提供） |
| `stripe` | `boolean` | `false` | 斑马纹 |
| `border` | `boolean` | `false` | 边框模式 |
| `virtual` | `boolean` | `false` | 虚拟滚动模式（需提供 `rowKey`；建议同时设置 `height` 与 `rowHeight`） |
| `height` | `number \| string` | — | 表格主体固定高度（px） |
| `rowHeight` | `number` | `40` | 虚拟模式行高（px，须与实际行高一致） |
| `rowSelection` | `TableRowSelection` | — | 行选择配置：`selectedRowKeys`（受控）/ `onChange` / `getCheckboxDisabled` |
| `className` | `string` | — | 附加到根节点的自定义类名 |
| `style` | `Record<string, string>` | — | 附加到根节点的内联样式（支持 CSS 变量如 `--xui-table-row-height`） |
| `onSortChange` | `(sort: TableSort) => void` | — | 排序变更回调 |
| `onRowClick` | `(record: TableRow, index: number) => void` | — | 行点击回调（选择列点击不触发） |

`TableColumn`：`{ key, title, width?, align?, sortable?, render? }`；`width` 数字按 px、字符串原样；`align` 为 `'left' | 'center' | 'right'`；`render: (record, index) => string`。

`TableSort`（事件载荷）：`{ key: string, order: 'asc' | 'desc' | null }`（`null` 表示已取消排序）。

`TableRowSelection`：`{ selectedRowKeys?: TableRowKey[], onChange?: (selectedRowKeys, selectedRows) => void, getCheckboxDisabled?: (record, index) => boolean }`；提供 `selectedRowKeys` 即受控（内部状态不变，仅回调）；未全选含半选时点击全选选中全部可选行。

`TableRowKey`：`string | number`（`rowKey` 字段取值）。

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `sortChange` | `onSortChange` | `{ key, order }` |
| `rowClick` | `onRowClick` | `record, index`（选择列点击不冒泡） |

| 插槽（Vue） | React 回调 | 说明 |
|-------------|------------|------|
| `empty` | `renderEmpty` | 空数据内容（覆盖默认"暂无数据"） |

### 边界场景处理

- 排序循环：新列升序起步，同列点击 升序 → 降序 → 取消（`sortKey` 置 `null`，恢复原序）；事件载荷始终携带点击列的 `key`
- `dataSource` 变化：保持当前排序状态对最新数据重排；排序操作不修改传入的原数组
- 单元格默认渲染：`null` / `undefined` 显示为空字符串
- `dataSource` 为空：渲染空态行（colspan 全列），有插槽 / 回调时用自定义内容
- `render` 返回值仅支持字符串（保持契约极简），富内容请扩展 cell 插槽（规划中）
- 虚拟滚动：仅渲染可视窗口行 + spacer 占位（保持原生 table 语义）；视口高度 `height`（数字按 px）与总占位由逻辑层统一计算，`viewportHeight` 为 0（隐藏容器）时窗口仍跟随数据
- 行选择：未提供 `selectedRowKeys` 为非受控（内部维护）；受控模式点击仅回调 `onChange` 不改内部状态；全选只选中可选行（`getCheckboxDisabled` 返回 true 的行被排除）；选择列单元格点击不触发 `onRowClick`

### 无障碍

- 可排序列表头 `aria-sort="ascending"` / `"descending"`（未排序省略）；排序按钮携带升降序双箭头图标（激活方向高亮）
- 表头 `scope="col"` 关联数据行
- 全选框同步 `indeterminate` 半选语义；行选择框携带行 `rowKey` 标注

### 注意事项

- 非受控排序：组件内部维护排序状态，外部通过 `sortChange` 感知；不做受控 `sortKey` prop（保持契约极简）
- 中文字符串排序按码点序（如 张三 < 李四 < 王五）
- 虚拟模式采用固定行高假设：实际行高必须与 `rowHeight` 一致（可用 CSS 变量 `--xui-table-row-height` 对齐），否则滚动定位漂移
- 行选择建议提供 `rowKey`；缺省用行下标时数据重排（排序）后选中集合不跟随行移动
- 样式类：根元素 `is-striped` / `is-bordered`，排序激活 `is-active`

## Spin 加载中

### 功能特性

- 独立模式：不提供内容时渲染独立旋转圆环（`spinning=false` 不渲染任何元素）
- 包裹模式：提供内容时渲染包裹容器，加载中内容模糊化（`filter: blur`）+ 半透明遮罩 + 居中圆环
- 三档尺寸 `sm | md | lg`（默认 `md`）
- 提示文本 `tip`（空串归一为 `null` 不渲染）
- 纯展示组件：无事件、无受控/非受控之分，`spinning` 由外部驱动

### 使用场景

- 页面 / 区块异步数据加载中的占位反馈
- 包裹任意内容块，加载时模糊 + 遮罩（替代整页 loading）
- 表格、卡片等容器局部加载态

### API

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| size | `'sm' \| 'md' \| 'lg'` | `'md'` | 尺寸（非法值收敛为 `md`） |
| spinning | `boolean` | `true` | 是否处于加载中 |
| tip | `string` | `null` | 加载提示文本（空串视为无） |

| 插槽 | 说明 |
|------|------|
| default（Vue `#default` / React children） | 包裹模式的内容；不提供则为独立模式 |

事件：无。

### 使用示例

```vue
<Spin size="lg" tip="加载中..." />
<Spin :spinning="loading">
  <div>被包裹内容</div>
</Spin>
```

```tsx
<Spin size="lg" tip="加载中..." />
<Spin spinning={loading}>
  <div>被包裹内容</div>
</Spin>
```

### 边界场景处理

- `size` 非法值收敛为 `md`；`tip` 空串归一为 `null`
- 包裹模式下 `spinning=false` 时遮罩与圆环不渲染，内容清晰展示
- 独立模式下 `spinning=false` 整个元素不渲染
- 选项变更未产生实际变化时不触发更新（no-op）

### 无障碍

- 包裹模式遮罩 `role="status"` + `aria-live="polite"`（加载状态变化可被读屏感知）
- 圆环 `aria-hidden`（装饰性动画不播报）

### 注意事项

- `spinning` 无内部状态，切换由外部受控驱动
- 包裹模式的模糊效果依赖内容的 `is-blur` 类切换（`pointer-events: none` 防止加载中交互）
- 样式类：独立 `xui-spin`，包裹 `xui-spin--wrapper` + `__mask` / `__content` / `__tip`

## Breadcrumb 面包屑

### 功能特性

- `items` 数据驱动渲染（`label` + 可选 `href` / `disabled`），末项自动标记当前页
- 可导航项渲染为 `<a>`（有 href）或可点击 label（无 href），末项 / 禁用项渲染为纯文本
- 自定义分隔符 `separator`（默认 `'/'`）
- 点击可导航项触发 `itemClick(item, index)`（末项与禁用项不触发）
- default 插槽可完全自定义渲染（覆盖 items 模式）

### 使用场景

- 层级导航路径展示
- 配合路由跳转（`itemClick` 回调中做路由跳转，href 可省略）

### API

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| items | `BreadcrumbItem[]` | `[]` | 面包屑项 `{ label, href?, disabled? }` |
| separator | `string` | `'/'` | 分隔符（空串回退 `'/'`） |
| onItemClick | `(item, index) => void` | — | 点击可导航项时触发 |

| 事件（Vue） | 载荷 | 说明 |
|------|------|------|
| item-click | `(item: BreadcrumbItem, index: number)` | 点击可导航项时触发（末项 / disabled 不触发） |

| 插槽 | 说明 |
|------|------|
| default（Vue `#default` / React children） | 自定义整体渲染，提供时覆盖 items 模式 |

### 使用示例

```vue
<Breadcrumb
  :items="[{ label: '首页', href: '#home' }, { label: '组件' }, { label: '当前页' }]"
  separator=">"
  @item-click="(item, index) => go(item)"
/>
```

```tsx
<Breadcrumb
  items={[{ label: '首页', href: '#home' }, { label: '组件' }, { label: '当前页' }]}
  separator=">"
  onItemClick={(item, index) => go(item)}
/>
```

### 边界场景处理

- 末项固定 `aria-current="page"`，点击不触发事件（当前页不可再导航）
- `disabled` 项渲染纯文本 + `cursor: not-allowed`，点击不触发事件
- `separator` 空串回退 `'/'`；分隔符 `aria-hidden`（读屏不播报）
- 越界 `selectItem(index)` 安全 no-op

### 无障碍

- 根元素 `<nav aria-label="面包屑">` + `<ol>` / `<li>` 结构
- 末项 `aria-current="page"`；分隔符 `aria-hidden="true"`

### 注意事项

- Vue 端回调 prop（`onItemClick`）通过 `Omit` 从 Props 类型剔除，事件走 `@item-click`
- `href` 项为真实 `<a>` 链接，浏览器默认导航行为由应用层决定（SPA 场景建议省略 href 或在回调中 `preventDefault`）
- 样式类：`is-active`（末项）/ `is-disabled` / `__link` / `__label` / `__separator`

## Skeleton 骨架屏

### 功能特性

- `loading=true` 渲染骨架占位（可选圆形头像 + 若干行条），`loading=false` 渲染真实内容（default 插槽 / children）

- 纯展示组件：无事件，`loading` 由外部驱动

### 使用场景

- 列表 / 卡片 / 详情页数据加载中的结构占位

### API

| avatar | `boolean` | `false` | 是否显示圆形头像占位 |
| rows | `number` | `3` | 文本行数（非法值收敛为 3） |

| 插槽 | 说明 |
|------|------|
| default（Vue `#default` / React children） | loading=false 时渲染的真实内容 |

事件：无。

### 使用示例

```vue
<Skeleton :loading="loading" avatar :rows="3">
  <div>真实内容</div>
</Skeleton>
```

```tsx
<Skeleton loading={loading} avatar rows={3}>
  <div>真实内容</div>
</Skeleton>
```

### 边界场景处理

- `rows` 非有限 / 非正数收敛为 3，小数 floor
- `loading=false` 且无内容时渲染 `null`（React）/ 空注释节点（Vue）
- 骨架图形 `aria-hidden`，避免读屏播报无意义占位

### 无障碍

- 骨架容器 `role="status"` + `aria-label="加载中"`

### 注意事项

- `loading` 无内部状态，切换由外部受控驱动
- 闪烁动画为 CSS `@keyframes xui-skeleton-loading`（`background-position` 渐变扫过）
- 样式类：`xui-skeleton` + `__avatar` / `__rows` / `__row`（`is-last` 末行 60% 宽）

## InputNumber 数字输入

### 功能特性

- 受控 / 非受控：`value` / `defaultValue` 类型 `number | null`（`null` 为有效空值，"用户清空了"）
- 步进按钮（上下箭头）+ 键盘操作（`↑` / `↓` 步进、`Enter` 提交输入）
- 边界 `min` / `max`（默认 ±Infinity），越界自动 clamp；`min > max` 自动交换
- 精度 `precision`（0-20 整数，非法视为不限制），显示与提交均按精度收敛
- 浮点步进防误差：整数域运算（`10^n` 放大后计算，`0.1 + 0.2 → 0.3`）
- 值不变时完全 no-op（不更新状态、不触发回调）

### 使用场景

- 数量、价格、百分比等有精度与边界要求的数字输入
- 键盘 / 按钮双通道步进调节

### API

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| value | `number \| null` | — | 受控值（提供即受控，`null` 为有效空值） |
| defaultValue | `number \| null` | — | 非受控初始值（非法值收敛为 `null`） |
| min / max | `number` | `±Infinity` | 边界（非有限值视为无边界，min > max 自动交换） |
| step | `number` | `1` | 步长（非正数收敛为 1） |
| precision | `number` | `null` | 精度（0-20 整数，非法视为不限制） |
| disabled | `boolean` | `false` | 禁用 |
| placeholder | `string` | — | 占位文本 |
| onChange | `(value: number \| null) => void` | — | 值提交时触发（清空 / 非法输入载荷为 `null`） |

| 事件（Vue） | 载荷 | 说明 |
|------|------|------|
| change / update:value | `(value: number \| null)` | 值提交时触发（清空 / 非法输入载荷为 `null`） |

插槽：无。

### 使用示例

```vue
<InputNumber
  v-model:value="num"
  :min="0"
  :max="10"
  :step="0.5"
  :precision="2"
  @change="(v) => console.log(v)"
/>
```

```tsx
<InputNumber
  value={num}
  min={0}
  max={10}
  step={0.5}
  precision={2}
  onChange={(v) => console.log(v)}
/>
```

### 边界场景处理

- 初始值收敛：非法（非有限）→ `null`，然后 precision 取整 + clamp
- 步进基准：当前值为 `null` 时以 `defaultValue`（仍空则 0）为基准
- 输入提交：空串 / 非法文本 → `null`；合法文本经 precision + clamp 收敛
- 边界步进 no-op：值已达边界时继续步进不触发回调（避免重复 onChange）
- `updateOptions`：min / max / precision 变更时对当前值重新收敛；受控值同步（`null` 有效）
- 禁用状态下步进 / 提交均忽略

### 无障碍

- 输入框 `role="spinbutton"` + `aria-valuenow` / `aria-valuemin` / `aria-valuemax`（有限边界才输出）
- `inputmode="decimal"` 引导数字键盘
- 步进按钮 `aria-label="增加" / "减少"`，`tabindex={-1}`（键盘走 `↑` `↓`）

### 注意事项

- **`null` 是有效受控值**：`value !== undefined` 即受控，传 `null` 表示"外部声明当前为空"，不会退化为非受控
- 值不变 no-op 语义与 Pagination `goTo` 一致：重复提交相同值只回调一次
- 编辑态（`inputText`）为组件内部自由文本，提交 / 步进后统一与逻辑收敛值对齐，不逐键回调
- Vue 端 `onChange` 通过 `Omit` 剔除，事件走 `@change` / `v-model:value`
- 样式类：`xui-input-number` + `__input` / `__step` / `__btn`

## Popconfirm 气泡确认

### 功能特性

- 点击触发元素弹出确认气泡（`content` 正文 + 确认 / 取消按钮），点击气泡外收起（不触发回调）
- 四方位 `top | bottom | left | right`（默认 `top`，CSS 包裹定位与 Tooltip 同机制）
- 按钮文本可自定义（`confirmText` 默认 `'确定'`、`cancelText` 默认 `'取消'`）
- `confirm` / `cancel` 双事件回调，确认 / 取消后自动收起
- `#content` 具名插槽（Vue）/ `renderContent` 回调（React）自定义正文
- 按钮复用 Button 类名（`.xui-button` / `--primary` / `--sm`），视觉与 Button 组件一致

### 使用场景

- 删除、下线、支付等二次确认场景（替代重型 Modal）
- 轻量操作确认，不打断页面上下文

### API

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| content | `string` | — | 气泡正文（插槽 / 回调可覆盖） |
| confirmText | `string` | `'确定'` | 确认按钮文本 |
| cancelText | `string` | `'取消'` | 取消按钮文本 |
| placement | `'top' \| 'bottom' \| 'left' \| 'right'` | `'top'` | 弹出方位（非法值收敛为 top） |
| disabled | `boolean` | `false` | 禁用（触发无效；运行时禁用自动收起已开气泡） |
| onConfirm | `() => void` | — | 确认回调 |
| onCancel | `() => void` | — | 取消回调 |

| 事件（Vue） | 载荷 | 说明 |
|------|------|------|
| confirm | — | 点击确认按钮时触发 |
| cancel | — | 点击取消按钮时触发 |

| 插槽 | 说明 |
|------|------|
| default（Vue `#default` / React children） | 触发元素 |
| content（Vue `#content` / React `renderContent`） | 自定义气泡正文 |

### 使用示例

```vue
<Popconfirm content="确定删除吗？" @confirm="del" @cancel="() => {}">
  <Button type="danger">删除</Button>
</Popconfirm>
```

```tsx
<Popconfirm content="确定删除吗？" onConfirm={del} onCancel={noop}>
  <Button type="danger">删除</Button>
</Popconfirm>
```

### 边界场景处理

- 未打开时 confirm / cancel / close 均 no-op（不触发回调）
- 点击气泡外区域收起但不触发任何回调（取消语义仅限点击"取消"按钮）
- 触发元素为禁用 Button 时原生不派发 click，气泡不弹出
- `updateOptions` 运行时禁用：自动收起已打开的气泡
- `placement` 非法值收敛为 `top`

### 无障碍

- 触发元素 `aria-describedby` 关联气泡 `id`
- 气泡 `role="tooltip"`，箭头 `aria-hidden`

### 注意事项

- 外部点击监听绑定 `document`（mousedown），组件卸载时移除
- 气泡为 CSS 包裹定位（相对根元素 absolute，非 portal），父级有 `overflow: hidden` 时可能被裁剪
- Vue 端 `onConfirm` / `onCancel` 通过 `Omit` 剔除，事件走 `@confirm` / `@cancel`
- 样式类：`xui-popconfirm` + `__trigger` / `__popper`（`is-top/bottom/left/right`）/ `__content` / `__arrow` / `__actions`

- **Modal 焦点陷阱 + 焦点恢复**：打开时记录 `document.activeElement` 并聚焦面板，关闭后焦点归还打开前元素；打开期间 Tab / Shift+Tab 循环约束在面板内（`trapFocus` 默认开启可关闭）。循环逻辑下沉 shared 层 `trapFocus(e, container)` 纯函数（`@xui/utils` 式 DOM 辅助，不持有状态），双端适配层仅在面板 keydown 时调用

- **InputNumber value 为 `number \| null` 契约**（经评审确认）：`null` 是有效受控值（"用户清空了"），`value !== undefined` 即受控；非法输入 / 清空载荷为 `null`

### 批次 2 修复记录

- **Vue 受控同步 bug（影响批次 1 组件）**：`withDefaults(defineProps<T>(), {...})` 配合解构返回值会禁用 Vue 3.5 的响应式解构（编译器警告证实），解构变量退化为一次性快照，`watchEffect` 依赖收集失效，导致受控 Props 变更无法同步视觉状态。修复：`RadioGroup.vue` / `Switch.vue` / `Checkbox.vue` 改为 `const props = withDefaults(...)`，解构快照仅用于逻辑层初始化，后续 Props 访问一律走 `props.xxx`；并补齐双端"受控 setProps 驱动视觉切换"测试用例
- **React Badge 包裹模式补齐 `state.visible` 判断**：count 隐藏时不再渲染空的 sup 元素（与 Vue 端对齐）
- **Radio 自身禁用守卫**：程序化事件（测试工具 `fireEvent` 等）会绕过原生 `disabled` 行为，双端 handleChange 增加自身禁用忽略 + DOM 恢复守卫

### 双端一致性保障

- `scripts/contract-test.ts` 校验矩阵覆盖每个组件的：事件（emits ↔ 回调 prop）、Props 齐全性、默认值（Vue 编译产物 props 选项 ↔ React 源码解构默认值 ↔ core 契约 spec）三方逐项比对
- Vue 端默认值必须写在 `withDefaults` 第二参数（才会编译进 props 选项）；解构模式中的等号默认值只是 setup 局部回退，契约测试会拦截此类不一致
- Vue 端 `value` / `defaultValue` 使用显式 `undefined` 默认值跳过 Boolean prop 缺省转换，保证"提供即受控"语义与 React 端对齐

### 已知限制

- 组件样式依赖 `@xui/styles`（BEM + CSS 变量），未引入主题 token 时使用降级值
- 长期驻留的 Vite dev server 若在 `@xui/core` 类型产物重建前启动，SFC 类型解析缓存可能被污染（表现为编译报 `Unresolvable type reference`），重启 dev server 即可恢复
