# 10 - 组件文档（通用组件库）

> **用途**：XUI 通用组件的功能特性、使用场景、API 说明与注意事项。
> **适用范围**：`@xui/vue` 与 `@xui/react` 双端组件，API 以 `@xui/core` 的 ComponentSpec 为唯一契约基准（见 [03-统一组件规范](./03-统一组件规范.md)）。
> **维护约定**：每新增一批组件，在本文件追加对应章节；API 变更需同步更新本文件与 `scripts/contract-test.ts` 校验矩阵。

---

## 组件总览

| 分类 | 组件 | 包路径 | 说明 |
|------|------|--------|------|
| 表单交互 | Switch | `@xui/vue` / `@xui/react` | 开关选择器 |
| 表单交互 | Checkbox | `@xui/vue` / `@xui/react` | 复选框（含半选态） |
| 数据展示 | Tag | `@xui/vue` / `@xui/react` | 标签（可关闭） |
| 反馈提示 | Alert | `@xui/vue` / `@xui/react` | 警告提示（可关闭） |
| 基础 | Button / Input / Modal | `@xui/vue` / `@xui/react` | 首批组件（见 playground） |

### 通用约定

- **受控 / 非受控**：提供 `value` 即受控（组件不自改状态，仅回调外部同步）；不提供则非受控，用 `defaultValue` 指定初始状态。Vue 端推荐 `v-model:value`（等价于 `value` + `@update:value`）。
- **事件映射**：core 契约的 `onXxx` 回调 prop，在 Vue 端映射为 `emit('xxx')`（如 `@change`、`@close`），在 React 端映射为 `onXxx`（如 `onChange`、`onClose`）。
- **插槽映射**：Vue 具名插槽 `#title` 对应 React `renderTitle` 回调；作用域插槽对应回调函数类型 Props。
- **样式**：双端共用 `@xui/styles` 单一来源的 BEM 类名（`xui-*`）与 CSS 变量主题（`--xui-*`），引入 `import '@xui/styles'` 即可。
- **尺寸**：统一 `sm | md`（Button/Input 为 `sm | md | lg`）。

## Switch 开关

### 功能特性

- 受控 / 非受控双模式，非受控模式内部自维护选中状态
- `sm / md` 两种尺寸
- `disabled` 禁用、`loading` 加载态（加载中切换被忽略，滑块显示 Spinner）
- 通过 `ref` 暴露 `focus()` 命令式聚焦（React 端 `SwitchRef`）

### 使用场景

布尔设置的即时开关：通知开关、功能启停、协议同意等二选一场景。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `boolean` | — | 受控选中状态（提供即受控） |
| `defaultValue` | `boolean` | `false` | 非受控初始状态 |
| `size` | `'sm' \| 'md'` | `'md'` | 尺寸 |
| `disabled` | `boolean` | `false` | 禁用 |
| `loading` | `boolean` | `false` | 加载中（切换被忽略） |
| `onChange` | `(value: boolean) => void` | — | 状态变更回调 |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `change` | `onChange` | 切换后的选中值 |
| `update:value` | — | `v-model:value` 回写 |

| Slots（Vue） | React | 说明 |
|--------------|-------|------|
| — | — | 无插槽 |

### 使用示例

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Switch } from '@xui/vue';

const enabled = ref(false);
</script>

<template>
  <!-- 受控（推荐 v-model） -->
  <Switch v-model:value="enabled" @change="(v) => console.log(v)" />
  <!-- 非受控 -->
  <Switch default-value size="sm" />
  <!-- 禁用 / 加载 -->
  <Switch disabled />
  <Switch loading />
</template>
```

```tsx
import { useState } from 'react';
import { Switch } from '@xui/react';

function Demo() {
  const [enabled, setEnabled] = useState(false);
  return (
    <>
      {/* 受控 */}
      <Switch value={enabled} onChange={setEnabled} />
      {/* 非受控 */}
      <Switch defaultValue size="sm" />
      <Switch disabled />
      <Switch loading />
    </>
  );
}
```

### 边界场景处理

- `disabled` / `loading` 状态下点击不触发任何回调（逻辑层 `toggle()` 直接忽略）
- 受控模式下外部未同步 `value` 时，组件视觉状态随外部值回退（严格受控语义）
- `loading` 由 `true` 变回 `false` 后恢复可交互

### 无障碍

- 根元素为 `<button role="switch">`，`aria-checked` 同步选中状态
- 禁用 / 加载时设置 `aria-disabled` 与 `disabled` 属性，阻止键盘触发
- 支持键盘 `Space` / `Enter` 触发（原生 button 语义）

### 注意事项

- Vue 端**不要**用 `:value="false"` 之外的方式"假装非受控"——提供 `value` 即进入受控模式；非受控请完全省略 `value`（Vue 的 Boolean prop 缺省会转 `false`，组件内部已通过 `withDefaults` 的显式 `undefined` 默认值规避，使用者无需关心，但请勿在中间层二次包装 Props 转发）
- 受控模式下请务必在 `change` / `update:value` 回调中回写 `value`，否则视觉状态不更新

## Checkbox 复选框

### 功能特性

- 受控 / 非受控双模式
- 半选态（`indeterminate`）：视觉显示横线，点击后切换为全选
- `disabled` 禁用
- 通过 `ref` 暴露 `focus()`（React 端 `CheckboxRef`）
- 默认插槽渲染标签文案

### 使用场景

多选列表、协议勾选、表格行选择（配合 `indeterminate` 实现全选/部分选中）。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `value` | `boolean` | — | 受控选中状态（提供即受控） |
| `defaultValue` | `boolean` | `false` | 非受控初始状态 |
| `disabled` | `boolean` | `false` | 禁用 |
| `indeterminate` | `boolean` | `false` | 半选状态 |
| `onChange` | `(value: boolean) => void` | — | 状态变更回调 |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `change` | `onChange` | 切换后的选中值 |
| `update:value` | — | `v-model:value` 回写 |

| Slots（Vue） | React | 说明 |
|--------------|-------|------|
| `default` | `children` | 标签内容 |

### 使用示例

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Checkbox } from '@xui/vue';

const agreed = ref(false);
</script>

<template>
  <Checkbox v-model:value="agreed">同意服务条款</Checkbox>
  <Checkbox :indeterminate="true">半选（点击后切全选）</Checkbox>
  <Checkbox disabled>禁用</Checkbox>
</template>
```

```tsx
import { useState } from 'react';
import { Checkbox } from '@xui/react';

function Demo() {
  const [agreed, setAgreed] = useState(false);
  return (
    <>
      <Checkbox value={agreed} onChange={setAgreed}>同意服务条款</Checkbox>
      <Checkbox indeterminate>半选（点击后切全选）</Checkbox>
      <Checkbox disabled>禁用</Checkbox>
    </>
  );
}
```

### 边界场景处理

- 半选态点击 → 切换为**全选**（不是取消），并清除半选视觉；非受控时逻辑层自动清除 `indeterminate`，受控时由外部管理
- `disabled` 时点击无效
- `indeterminate` 与 `checked` 同时提供时，视觉以 `indeterminate`（横线）优先

### 无障碍

- 使用原生 `<input type="checkbox">`，键盘与读屏行为完全继承浏览器原生语义
- 半选状态通过 DOM 属性 `indeterminate` 同步（读屏可感知）
- 外层 `label` 包裹，点击文案即可切换

### 注意事项

- `indeterminate` 既是视觉态也是交互初态：受控模式下若外部一直传 `indeterminate: true`，每次点击都会切为全选并触发 `change(true)`，需要外部自行同步清除
- 半选是 DOM 属性而非 HTML attribute，React 端经 `useEffect` + ref 同步，Vue 端经 `.prop` 修饰符绑定，均已在实现内处理

## Tag 标签

### 功能特性

- 5 种语义类型：`default / primary / success / warning / danger`
- `sm / md` 两种尺寸
- `closable` 可关闭：显示关闭按钮，点击后隐藏并触发 `close`
- 关闭为组件内部状态（`visible`），关闭后组件渲染为 `null`

### 使用场景

内容标记、分类标注、筛选条件回显、列表条目状态展示。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `type` | `'default' \| 'primary' \| 'success' \| 'warning' \| 'danger'` | `'default'` | 语义类型 |
| `size` | `'sm' \| 'md'` | `'md'` | 尺寸 |
| `closable` | `boolean` | `false` | 是否可关闭 |
| `onClose` | `() => void` | — | 关闭回调（组件隐藏后触发） |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `close` | `onClose` | 无 |

| Slots（Vue） | React | 说明 |
|--------------|-------|------|
| `default` | `children` | 标签内容 |

### 使用示例

```vue
<template>
  <Tag>default</Tag>
  <Tag type="success">success</Tag>
  <Tag type="danger" size="sm">danger</Tag>
  <Tag closable @close="onClose">可关闭</Tag>
</template>
```

```tsx
<Tag type="success">success</Tag>
<Tag closable onClose={() => console.log('closed')}>可关闭</Tag>
```

### 边界场景处理

- 重复触发关闭（连续点击 ×）：`handleClose()` 幂等，仅首次生效
- 关闭是纯前端行为（内部 `visible` 状态），如需"删除后从数据源移除"，在 `close` 回调中自行处理数据

### 无障碍

- 关闭按钮为原生 `<button>`，`aria-label="close"`，可键盘聚焦触发

### 注意事项

- 组件关闭后不再渲染（`v-if` / `return null`），如需恢复显示需重建组件或自行管理外层 `v-if`
- `onClose` 在组件隐藏**之后**触发，回调中不要再操作该组件实例

## Alert 警告提示

### 功能特性

- 4 种语义类型：`info / success / warning / error`，各配对应图标
- `title` 标题 + `description` 描述两级信息结构
- `showIcon` 显示类型图标
- `closable` 可关闭，关闭后隐藏并触发 `close`
- 插槽体系：标题、描述、图标均可自定义

### 使用场景

页面内重要信息的强提示：操作结果反馈、表单校验汇总、系统公告、危险操作警示。

### API

| Props | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `type` | `'info' \| 'success' \| 'warning' \| 'error'` | `'info'` | 语义类型 |
| `title` | `string` | — | 标题 |
| `description` | `string` | — | 描述（default 插槽的回退内容） |
| `closable` | `boolean` | `false` | 是否可关闭 |
| `showIcon` | `boolean` | `false` | 是否显示类型图标 |
| `onClose` | `() => void` | — | 关闭回调（组件隐藏后触发） |

| Events（Vue） | React 回调 | 载荷 |
|---------------|------------|------|
| `close` | `onClose` | 无 |

| Slots（Vue） | React 回调 | 说明 |
|--------------|------------|------|
| `default` | `children` | 描述内容（覆盖 `description`） |
| `title` | `renderTitle` | 标题（覆盖 `title`） |
| `icon` | `renderIcon` | 类型图标（覆盖默认图标，`showIcon` 开启时生效） |

### 使用示例

```vue
<template>
  <Alert title="Info" description="普通信息提示" show-icon />
  <Alert type="success" title="Success" description="操作已完成" show-icon />
  <Alert type="warning" title="Warning" description="请检查输入" show-icon />
  <Alert type="error" title="Error" description="出错了" show-icon closable @close="onClose" />

  <!-- 自定义标题与描述 -->
  <Alert type="info" show-icon>
    <template #title>自定义标题</template>
    支持 <b>HTML</b> 的描述内容
  </Alert>
</template>
```

```tsx
<Alert title="Info" description="普通信息提示" showIcon />
<Alert type="error" title="Error" description="出错了" showIcon closable onClose={handleClose} />

{/* 自定义标题与描述 */}
<Alert type="info" showIcon renderTitle={() => <em>自定义标题</em>}>
  支持 <b>HTML</b> 的描述内容
</Alert>
```

### 边界场景处理

- 重复触发关闭：`handleClose()` 幂等，仅首次生效
- `title` 与 `description` 均未提供时仍渲染容器（可完全由插槽接管内容）
- 优先级：插槽 / render 回调 > 同名 prop（`#title` > `title`，`#default` > `description`）

### 无障碍

- 根元素 `role="alert"`：动态出现时读屏自动播报
- 图标容器 `aria-hidden="true"`，避免读屏重复朗读
- 关闭按钮 `aria-label="close"`

### 注意事项

- `role="alert"` 适合**动态插入**的提示；对常驻静态提示建议外层自行降级为 `role="status"`（如需）
- 图标为 `@xui/icons` 单一来源 SVG，自定义图标时用 `#icon` / `renderIcon` 完整替换

### 双端一致性保障

- `scripts/contract-test.ts` 校验矩阵覆盖每个组件的：事件（emits ↔ 回调 prop）、Props 齐全性、默认值（Vue 编译产物 props 选项 ↔ React 源码解构默认值 ↔ core 契约 spec）三方逐项比对
- Vue 端默认值必须写在 `withDefaults` 第二参数（才会编译进 props 选项）；解构模式中的等号默认值只是 setup 局部回退，契约测试会拦截此类不一致
- Vue 端 `value` / `defaultValue` 使用显式 `undefined` 默认值跳过 Boolean prop 缺省转换，保证"提供即受控"语义与 React 端对齐

### 已知限制

- 组件样式依赖 `@xui/styles`（BEM + CSS 变量），未引入主题 token 时使用降级值
- 长期驻留的 Vite dev server 若在 `@xui/core` 类型产物重建前启动，SFC 类型解析缓存可能被污染（表现为编译报 `Unresolvable type reference`），重启 dev server 即可恢复
