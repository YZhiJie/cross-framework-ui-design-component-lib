# 03 - 统一组件规范

## 概述

本章定义跨框架组件库的统一规范，确保 Vue 和 React 双端组件在 API 层面行为一致。所有规范在 `@xui/core` 抽象层以 TypeScript 类型定义固化，并通过 CI 自动化校验双端实现是否对齐。

---

## 一、Props 约定

### 1.1 命名规范

| 规则 | 约定 | 示例 |
|------|------|------|
| 命名风格 | camelCase（TS 层）/ kebab-case（Vue 模板） | `loadingText` / `loading-text` |
| 布尔属性 | 使用 `is-` 或行为性前缀，避免歧义 | `isDisabled` → `disabled`（遵循原生语义） |
| 枚举值 | 小写字符串联合类型 | `type?: 'default' \| 'primary' \| 'danger'` |
| 回调属性 | 一律 `on` 前缀 + 驼峰 | `onClose` / `onVisibleChange` |
| 尺寸类 | 使用 `sm / md / lg` 三档 | `size?: 'sm' \| 'md' \| 'lg'` |
| 受控属性 | `value` + `onChange` 对（React 风格为基准） | `value` / `onValueChange` |
| v-model 兼容 | Vue 端额外支持 v-model 语法糖 | `v-model` = `:value` + `@update:value` |

### 1.2 Props 类型定义模板

```typescript
// @xui/core/src/components/modal/types.ts

export interface ModalProps {
  // --- 可见性 ---
  /** 是否显示弹窗 */
  visible: boolean;                          // 必填，受控

  /** 是否支持 esc 关闭 */
  escToClose?: boolean;                       // 可选，默认 true

  // --- 尺寸 ---
  /** 弹窗宽度 */
  width?: string | number;                    // 默认 '520px'

  // --- 行为 ---
  /** 是否遮罩点击关闭 */
  maskClosable?: boolean;                      // 默认 true

  /** 关闭时是否销毁组件 */
  destroyOnClose?: boolean;                    // 默认 false

  // --- 回调 ---
  /** 关闭时触发 */
  onClose?: (e: { source: 'mask' | 'esc' | 'button' }) => void;

  /** 打开动画结束 */
  onAfterOpen?: () => void;

  /** 关闭动画结束 */
  onAfterClose?: () => void;
}

export const modalDefaultProps: Partial<ModalProps> = {
  escToClose: true,
  width: '520px',
  maskClosable: true,
  destroyOnClose: false,
};
```

### 1.3 Vue/React Props 传递对比

| 特性 | Vue 3 | React | 统一约定 |
|------|-------|-------|----------|
| 传递方式 | `:visible="true"` | `visible={true}` | 属性名相同，语法各用各的 |
| 布尔简写 | `<Modal visible />` | `<Modal visible />` | 双端一致支持 |
| 事件回调 | `@close="handler"` | `onClose={handler}` | Vue 用 `@` 语法糖，React 用 `on` 前缀 |
| v-model | `v-model:visible` | 不支持，需手写 | Vue 端额外提供 v-model 语法糖 |
| 默认值 | `withDefaults()` | `defaultProps` / 解构默认 | 在 `@xui/core` 统一定义默认值 |
| 必填校验 | `defineProps<T>()`（TS 检查）| TS 检查 | 统一用 TypeScript 强约束 |

### 1.4 v-model 双端统一方案

```typescript
// @xui/core 提供统一的 useModel 工厂
// 核心层提供逻辑，适配层各自实现语法糖

// Vue 端 —— 标准 v-model
// <MyInput v-model="value" />
// 等价于 :value + @update:value

// React 端 —— 受控组件
// <MyInput value={value} onValueChange={setValue} />

// 统一 Props 定义
export interface InputProps {
  value: string;
  onValueChange?: (value: string) => void;
}
```

Vue 适配层额外暴露 `modelValue` + `update:modelValue` 事件以兼容 v-model 语法糖，内部逻辑完全一致。

## 二、事件处理机制

### 2.1 事件命名规范

| 事件类别 | 命名规则 | 示例 |
|---------|----------|------|
| DOM 事件 | `on` + 事件名（首字母大写） | `onClick` / `onFocus` |
| 自定义行为事件 | `on` + 动词（首字母大写） | `onClose` / `onSubmit` |
| 状态变更事件 | `on` + 名词 + `Change` | `onVisibleChange` / `onValueChange` |
| 动画结束事件 | `onAfter` + 动作 | `onAfterOpen` / `onAfterClose` |
| 校验事件 | `on` + `Validate` / `Error` | `onValidate` / `onValidationError` |

### 2.2 事件载荷规范

```typescript
// 所有事件载荷统一为对象格式（除简单 DOM 事件）
// 好的约定：
export interface SelectEvents {
  onSelect: (e: { value: string; label: string; index: number }) => void;
  onChange: (e: { value: string; oldValue: string }) => void;
  onClear: () => void; // 无载荷时可省略
}

// 不好的约定（避免）：
// onSelect: (value: string) => void;  // 载荷含义不清，扩展困难
```

### 2.3 Vue/React 事件映射

```
抽象层契约             Vue 适配层                 React 适配层
┌──────────┐    ┌───────────────────┐    ┌──────────────────┐
│ onClose  │ ──>│ defineEmits<{     │ ──>│ Props: {         │
│          │    │   (e:'close',     │    │   onClose?: ()   │
│          │    │    payload)=>void │    │   => void        │
│          │    │ }>()              │    │ }                │
└──────────┘    └───────────────────┘    └──────────────────┘
                  使用: @close            使用: onClose={}
```

### 2.4 事件冒泡策略

| 策略 | 说明 | 示例 |
|------|------|------|
| 透传 DOM 事件 | 组件内部处理后再 emit 给父组件 | Button 点击 → 内部 loading 逻辑 → `onClick` |
| 拦截阻止 | 组件内部处理完毕后不再向上传播 | 弹窗内部点击不触发外部 onClick |
| 自定义事件 | 非 DOM 原生事件，纯逻辑触发 | Select 选择变化 → `onChange` |

## 三、插槽 / Children 映射规则

### 3.1 映射总表

| 抽象层 Slot 定义 | Vue 适配层 | React 适配层 |
|------------------|-----------|-------------|
| `default` 插槽 | `<slot />` | `children` |
| 具名插槽 `header` | `<slot name="header" />` | `renderHeader?: () => ReactNode` |
| 作用域插槽 | `<slot :item="item" />` | `renderItem?: (item) => ReactNode` |
| 默认内容 | `<slot>fallback</slot>` | `children ?? <Fallback />` |
| 多插槽 | 多个 `<slot name="xxx" />` | 多个 `renderXxx` 回调 |

### 3.2 映射规则详解

#### 默认插槽

```typescript
// 抽象层
export interface CardSlots {
  default: {};
}

// Vue
<template>
  <div class="xui-card">
    <slot />
  </div>
</template>

// React
function Card({ children }: { children?: React.ReactNode }) {
  return <div className="xui-card">{children}</div>;
}
```

#### 具名插槽

```typescript
// 抽象层
export interface ModalSlots {
  default: {};
  header: {};
  footer: {};
}

// Vue
<template>
  <div class="xui-modal">
    <header><slot name="header" /></header>
    <main><slot /></main>
    <footer><slot name="footer" /></footer>
  </div>
</template>

// React —— 约定: 具名插槽映射为 renderXxx 回调 Props
interface ModalComponentProps extends ModalProps {
  children?: React.ReactNode;        // default slot
  renderHeader?: () => React.ReactNode;  // header slot
  renderFooter?: () => React.ReactNode;  // footer slot
}

function Modal({ children, renderHeader, renderFooter }: ModalComponentProps) {
  return (
    <div className="xui-modal">
      <header>{renderHeader?.()}</header>
      <main>{children}</main>
      <footer>{renderFooter?.()}</footer>
    </div>
  );
}
```

#### 作用域插槽

```typescript
// 抽象层
export interface ListSlots {
  default: { item: ListItem; index: number };
  empty: {};
}

// Vue —— 作用域插槽
<template>
  <div class="xui-list">
    <div v-for="(item, index) in items" :key="item.id">
      <slot :item="item" :index="index" />
    </div>
    <div v-if="items.length === 0" class="xui-list__empty">
      <slot name="empty">
        <span>暂无数据</span>
      </slot>
    </div>
  </div>
</template>

// 使用: <template #default="{ item, index }">

// React —— 回调 Props
interface ListComponentProps extends ListProps {
  children?: (item: ListItem, index: number) => React.ReactNode;
  renderEmpty?: () => React.ReactNode;
}

function List({ items, children, renderEmpty }: ListComponentProps) {
  return (
    <div className="xui-list">
      {items.length === 0 ? (
        <div className="xui-list__empty">
          {renderEmpty?.() ?? <span>暂无数据</span>}
        </div>
      ) : (
        items.map((item, index) => (
          <div key={item.id}>{children?.(item, index)}</div>
        ))
      )}
    </div>
  );
}

// 使用: <List items={data}>{(item, index) => <Card item={item} />}</List>
```

### 3.3 命名映射约定

```
Vue slot name        →    React prop name
────────────────────────────────────────
default              →    children
header               →    renderHeader
footer               →    renderFooter
prefix               →    renderPrefix
suffix               →    renderSuffix
empty                →    renderEmpty
item (作用域)         →    children (回调函数)
```

**规则：具名插槽 `xxx` → React `renderXxx`；作用域插槽 `xxx` → React `renderXxx(params)` 或 `children(params)`**

## 四、生命周期对应关系

### 4.1 生命周期映射总表

| 抽象层阶段 | Vue 3 | React | 触发时机 |
|-----------|-------|-------|---------|
| 挂载前 | `onBeforeMount` | (无直接等价) | DOM 插入前 |
| 挂载后 | `onMounted` | `useEffect(() => {}, [])` | DOM 插入后 |
| 更新前 | `onBeforeUpdate` | (无直接等价) | 更新 DOM 前 |
| 更新后 | `onUpdated` | `useEffect(() => {})` (无空依赖) | 更新 DOM 后 |
| 卸载前 | `onBeforeUnmount` | `useEffect(() => cleanup, [])` 的 cleanup | DOM 移除前 |
| 卸载后 | `onUnmounted` | (无直接等价) | DOM 移除后 |

### 4.2 统一生命周期抽象

```typescript
// @xui/shared/src/lifecycle.ts

export interface LifecycleHooks {
  onMount?: () => void | (() => void); // 返回清理函数
  onUnmount?: () => void;
  onUpdate?: (prevProps: any, nextProps: any) => void;
}

/**
 * 统一生命周期管理 —— 框架无关
 * 适配层负责在框架生命周期中调用这些 hooks
 */
export function createLifecycle(hooks: LifecycleHooks) {
  return {
    mount() { return hooks.onMount?.(); },
    unmount() { hooks.onUnmount?.(); },
    update(prev: any, next: any) { hooks.onUpdate?.(prev, next); },
  };
}
```

### 4.3 双端适配实现

```typescript
// Vue 适配层 —— 桥接统一生命周期
import { onMounted, onBeforeUnmount, onUpdated } from 'vue';

function useLifecycleAdapter(hooks: LifecycleHooks) {
  let cleanup: (() => void) | void;

  onMounted(() => {
    cleanup = hooks.onMount?.();
  });

  onBeforeUnmount(() => {
    cleanup?.();
    hooks.onUnmount?.();
  });

  onUpdated(() => {
    // Vue onUpdated 无 prevProps 参数，需通过 watchEffect 获取
  });
}
```

```tsx
// React 适配层 —— 桥接统一生命周期
import { useEffect, useRef } from 'react';

function useLifecycleAdapter<P>(props: P, hooks: LifecycleHooks) {
  const prevProps = useRef(props);

  // mount + unmount
  useEffect(() => {
    const cleanup = hooks.onMount?.();
    return () => {
      cleanup?.();
      hooks.onUnmount?.();
    };
  }, []);

  // update
  useEffect(() => {
    hooks.onUpdate?.(prevProps.current, props);
    prevProps.current = props;
  });
}
```

## 五、样式隔离方案

### 5.1 方案选型对比

| 方案 | Vue SFC `<style scoped>` | CSS Modules | CSS-in-JS | Shadow DOM |
|------|:-:|:-:|:-:|:-:|
| Vue 原生支持 | ✅ 原生 | ✅ 需配置 | 需第三方 | ✅ |
| React 原生支持 | ❌ | ✅ 需配置 | ✅ 多方案 | ✅ |
| 双端统一 | ❌ 各写各的 | ✅ 完美统一 | ✅ 完美统一 | ✅ |
| 运行时开销 | 0 | 0 | 1-5KB | 0 |
| SSR 兼容 | ✅ | ✅ | 需配置 | 差 |
| 类名可读性 | `xui-btn__text` | `_xui-btn__text_1a2b` | 动态 hash | 原始 |
| DevTools 调试 | 好 | 一般 | 一般 | 差(Shadow) |

### 5.2 推荐方案：CSS Modules + BEM 命名

**双端统一使用 CSS Modules**，配合 BEM 命名规范：

```
组件目录结构:
button/
├── button.tsx          (React 组件)
├── button.vue          (Vue 组件)
├── button.module.scss  (共享样式，CSS Modules)
├── button.module.css   (编译产物，纯 CSS)
├── types.ts            (Props 类型)
└── __tests__/
    └── button.test.ts
```

#### BEM 命名规范

```scss
// button.module.scss
.xui-button {
  // Block
  display: inline-flex;
  align-items: center;

  &--primary { color: var(--xui-color-primary); }   // Modifier
  &--sm { padding: 4px 8px; }                       // Modifier
  &--lg { padding: 8px 16px; }                      // Modifier

  &__icon { margin-right: 4px; }                     // Element
  &__content { font-size: 14px; }                   // Element

  &.is-disabled { opacity: 0.5; }                   // State
  &.is-loading { cursor: wait; }                   // State
}
```

#### Vue 端使用

```vue
<script setup>
import styles from './button.module.scss';
</script>

<template>
  <button :class="[
    styles['xui-button'],
    styles[`xui-button--${props.type}`],
    { [styles['is-disabled']]: disabled }
  ]">
    ...
  </button>
</template>
```

#### React 端使用

```tsx
import styles from './button.module.scss';

export const Button = ({ type, disabled }) => (
  <button className={cn(
    styles['xui-button'],
    styles[`xui-button--${type}`],
    { [styles['is-disabled']]: disabled }
  )}>
    ...
  </button>
);
```

### 5.3 CSS 变量主题系统

通过 CSS 自定义属性（CSS Variables）实现主题定制，双端通用：

```scss
// @xui/styles/src/theme/tokens.scss
:root {
  // 颜色
  --xui-color-primary: #1677ff;
  --xui-color-success: #52c41a;
  --xui-color-danger: #ff4d4f;
  --xui-color-text: rgba(0, 0, 0, 0.88);
  --xui-color-text-secondary: rgba(0, 0, 0, 0.65);

  // 尺寸
  --xui-border-radius-sm: 4px;
  --xui-border-radius-md: 6px;
  --xui-border-radius-lg: 8px;

  // 字体
  --xui-font-size-sm: 12px;
  --xui-font-size-md: 14px;
  --xui-font-size-lg: 16px;

  // 动画
  --xui-transition-fast: 100ms ease;
  --xui-transition-base: 200ms ease;
}
```

用户覆盖主题只需修改 CSS 变量，无需修改组件代码：

```css
/* 深色主题 */
.dark-theme {
  --xui-color-primary: #1668dc;
  --xui-color-text: rgba(255, 255, 255, 0.85);
  --xui-color-text-secondary: rgba(255, 255, 255, 0.65);
}
```

## 规范检查清单

每个新增组件 PR 必须通过以下检查：

- [ ] Props 类型在 `@xui/core` 统一定义，Vue/React 适配层引用同一类型
- [ ] 事件名遵循 `on` 前缀 + 驼峰命名
- [ ] 所有事件载荷为对象格式（简单 DOM 事件除外）
- [ ] 具名插槽映射为 React 的 `renderXxx` 回调
- [ ] 作用域插槽映射为 React 的回调函数 Props
- [ ] 生命周期通过 `createLifecycle` 统一管理
- [ ] 样式使用 CSS Modules + BEM 命名
- [ ] CSS 变量前缀为 `--xui-`
- [ ] Vue/React 两端的 Props 默认值一致
- [ ] CI 中 `contract-test` 通过（自动校验双端 API 对齐）
