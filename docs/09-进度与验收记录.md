## 关键技术决策记录

1. **Vue defineEmits 必须用元组形式**：Vue 3.5.43 的 `ShortEmits<T>` 使用 `...args: T[K]` 直接展开，仅支持 `{ click: [event: MouseEvent] }`，不支持 `@xui/core` 中调用签名形式 `(event: MouseEvent) => void`。SFC 内使用内联元组类型声明，Props 类型仍从 @xui/core 导入（`Omit<XxxProps, 'onClick'>`）。
2. **React useSyncExternalStore 需快照缓存**：逻辑工厂 `getState()` 每次返回新对象引用，直接传入会导致无限重渲染。`use-logic-state.ts` 用 useRef 缓存快照、subscribe 回调里先更新缓存再触发 onStoreChange。
3. **tsconfig paths 指向 dist/types**：适配层包的 paths 若指向兄弟包源码（`../core/src`），会因文件在 rootDir 之外触发 TS6059。已改为指向 `../core/dist/types/index.d.ts`，构建顺序由 turbo 依赖保证。
4. **双端共用 BEM 类名**：Vue 与 React 版组件使用同一套类名（`xui-button`、`is-loading` 等），各自包内维护一份 `components.css`，保证视觉一致且无跨包运行时依赖。

## 环境与工程约束（踩坑记录）

| 约束 | 说明 |
|------|------|
| PowerShell | 不支持 `&&`（用 `;` 分隔）；不支持 heredoc（commit message 用单行 `-m`） |
| pnpm v11 | `pnpm.onlyBuiltDependencies` 必须放在 pnpm-workspace.yaml（不放 package.json）；要求 Node >= 22.13 |
| CI | node-version: 22；pnpm/action-setup@v4 不写 version 字段（读 packageManager）；不要同时配置 push 与 workflow_run 触发（会重复执行） |
| ESLint 9 flat config | lint 脚本用 glob 模式，不支持 `--ext`；Vue SFC 需显式关闭 `no-undef`（TS 已做类型检查） |
| Write/Edit 工具 | 偶发 IDE Command timeout 但修改实际生效——先 Read 确认再决定是否重写 |
| git push | github.com 443 偶发连接超时，需多次重试；`origin/main` 本地 ref 更新即代表推送成功（stderr 的 NativeCommandError 是 git 进度输出的正常现象） |
| pnpm install | 需要访问 pnpm 缓存目录，沙箱环境下需 `dangerouslyDisableSandbox: true` |
| 验证命令 | `pnpm build --force`、`pnpm lint`、`pnpm type-check`、`pnpm test`（turbo 编排，可加 `--filter @xui/xxx`） |
